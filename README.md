# FlightSuit

라이언·춘식이 같은 캐릭터를 아이언맨 슈트로 디자인해서, 슈트를 입고 날아다니며 마을을 지키고 키우는 마인크래프트 Forge 모드입니다.

- 기획과 의도, 로드맵은 [DESIGN.md](DESIGN.md)에 정리되어 있습니다.
- M1~M16과 그 뒤 1~4차 피드백 반영분은 2026-10-10 인게임 테스트를 통과했습니다.
- **M17** (슈트 3벌 기술·궁극기 키 `V`·팬텀 기술 훔치기, 컷신 엔진과 드래곤볼 1~4장 재구성, 서쪽 도시·나메크 마을)은 구현을 마치고 **인게임 테스트 전**입니다. 따라 할 테스트 목록은 [docs/TEST_PLAN.md](docs/TEST_PLAN.md), 설계는 [docs/WORK_ORDER_M17.md](docs/WORK_ORDER_M17.md).
- 게임 안에서는 **플라이트 슈트 안내서**(처음 접속하면 받음)와 아이템 **Shift 툴팁**으로 조작법을 볼 수 있고, JEI가 있으면 R/U로 조합법이 나옵니다.
- 개인 프로젝트입니다.

## 실행

```bash
./gradlew runClient     # 개발용 클라이언트 실행
./gradlew build         # build/libs/ 에 모드 jar 생성
```

실제 마인크래프트에서 쓰려면 이 모드 jar와 함께 [PlayerAnimator](https://maven.kosmx.dev/dev/kosmx/player-anim/player-animation-lib-forge/) Forge 1.20 버전을 `mods` 폴더에 넣어야 합니다. 조합법을 R/U로 보려면 [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) 1.20.1 Forge 버전도 넣으세요 (없어도 모드는 동작).

## 현재 기능 (M1 ~ M17)

크리에이티브 탭 "플라이트 슈트"에서 모든 아이템과 블록을 꺼낼 수 있습니다. **슈트가 든 캡슐**로 바로 써 보거나, 스테이션에 슈트를 넣고 이디스 안경으로 불러 보세요.

### 착용 방법

| 방법 | 연출 |
|---|---|
| **이디스 안경 + `G`** | 메인 스테이션의 슈트가 스테이션 방향에서 날아와 착용됩니다 (Mark 42) |
| **떨어지는 중에 호출** | 큰대자 자세로 떨어지면 슈트 전체가 위에서 내리꽂히며 감싸고, 리펄서로 급제동해 호버링합니다 (Mark VII) |
| **스테이션 빈손 우클릭** | 로봇 팔들이 서 있는 슈트를 분해해 들어 올리고, 플랫폼으로 걸어 들어가면 부츠 → 레깅스 → 흉갑 → 헬멧 순으로 입혀 줍니다 (아이언맨 2) |
| **슈트 캡슐 우클릭 / `G`** | 주변에서 파츠가 날아와 착용됩니다 (휴대용 비상 슈트) |

- 착용 연출 동안 카메라가 3인칭으로 바뀌고, 이동이 막히며 무적입니다.
- **착용 중 스테이션 빈손 우클릭**: 플랫폼으로 걸어 들어가면 팔들이 헬멧부터 벗겨 내고, 앞으로 걸어 나오면 빈 슈트를 다시 세워 보관합니다.

### 조작키

| 키 | 동작 |
|---|---|
| `G` 짧게 (풀세트 착용 중) | 슈트에서 걸어 나옵니다. 빈 슈트는 그 자리에 남아 **동료**가 됩니다 |
| `G` 짧게 (부분 착용 중) | 수납합니다 (이디스 안경 + 메인 스테이션이 있으면 스테이션으로 귀환, 아니면 캡슐) |
| `G` 짧게 (미착용) | 근처 동료 슈트가 날아와 입혀집니다 → 동료가 없으면 메인 스테이션에서 호출 → 그것도 없으면 캡슐 |
| `G` 길게 | 모든 동료 슈트가 귀환하고, 입은 슈트도 귀환/수납합니다 |
| `H` | 조준한 대상을 동료 슈트가 공격합니다 (허공 조준 시 공격 중지) |
| `R` | 슈트 휠 (이디스 안경 필요): 클릭 = 동료로 출격 · Shift+클릭 = 갈아입기 · Ctrl+클릭 = 원격 조종 · 우클릭 = 메인 스테이션 지정 · 가운데 = 총력 모드 |
| `Z` 짧게 | 패링: 0.3초 안에 들어온 공격의 피해를 80% 막고 공격자에게 반격 (넉백 + 피해 + 2초 기절). 흉갑 필요. **팬텀 Mark 3은 대신 순간이동 조준**, 트랭크스 Mark 5는 **검 패링** (아래) |
| `Z` 길게 | 나노 에너지 쉴드: 앞쪽에서 오는 근접·화살·폭발을 막음 (화살은 튕김). 유지하는 동안 전력 소모, 천천히 걸음 |
| 빈손 우클릭 (누르고 있기) | 주무기 연속 발사 (흉갑 착용 시). 몹을 조준해도 발사됩니다. 주민·말·내 동료, 문·상자 같은 블록은 그대로 사용하고, 웅크리면 항상 블록을 사용합니다 |
| `X` | 슈트 스킬 1 (Mark 1·50 미사일, Mark 3 저지먼트 드로우, Mark 4 회전 베기, Mark 5 버닝 어택, Mark 44 피스톤 펀치) |
| `C` | 슈트 스킬 2 (Mark 1·50 유니빔, Mark 2 빙결 폭발, Mark 3 카드 대결, Mark 4 클로샷, Mark 5 섬광 베기, Mark 44 지면 강타) |
| `V` | **궁극기** (Mark 3 템페스트, Mark 5 초사이어인 켜기/끄기). 다른 슈트는 아직 없음 |
| `B` | **훔친 기술 쓰기** (Mark 3: `Z`를 길게 눌러 훔친 적의 기술) |
| 스페이스 2번 / 달리기 + 앞 | 비행 / 고속 비행 (풀세트) |

**도움말**: 처음 접속하면 **플라이트 슈트 안내서**를 받습니다 (우클릭으로 읽기, 18쪽: 시작하기·키·슈트별 기술·마을·우주. 잃어버리면 책 + 레드스톤). 우리 아이템에 마우스를 올리고 **Shift**를 누르면 사용법이 툴팁에 나옵니다. 키 이름은 지금 설정된 키로 표시됩니다. JEI가 있으면 **R**(조합법)·**U**(쓰임새)와 아이템 정보 페이지도 있습니다.

### 스테이션 여러 개와 슈트 휠

- 써 본 스테이션은 모두 기억됩니다. **메인 스테이션**(G로 부르는 곳)은 처음 쓴 스테이션이거나, 웅크리고 우클릭한 스테이션입니다.
- 슈트는 원래 있던 스테이션을 기억해서, 귀환할 때 그 스테이션으로 돌아갑니다 (없거나 차 있으면 메인 스테이션, 그다음 캡슐).
- **슈트 휠 (`R`)**: 스테이션에 있는 슈트, 나가 있는 동료, 캡슐을 카드로 보여 줍니다.
  - 클릭: 동료로 출격. 슈트가 자기 스테이션의 열린 앞쪽으로 이륙해 몸을 눕힌 비행 자세로 날아옵니다. 144칸보다 먼 스테이션의 슈트는 그 방향 하늘 저편에서 나타나 날아옵니다.
  - Shift+클릭: 갈아입기. 옛 슈트에서 뛰쳐나오고 새 슈트가 입혀지며, 옛 슈트는 동료로 남습니다. 날던 중이면 떨어지는 나를 새 슈트가 낚아챕니다.
  - 가운데: **총력 모드 (하우스 파티 프로토콜)**. 스테이션의 슈트가 전부 동료로 출격합니다 (최대 4기).

### 원격 조종

멀리 있는 슈트에 접속해서 직접 조종합니다 (아이언맨 3).

- 슈트 휠에서 동료나 스테이션 슈트 카드를 **Ctrl+클릭**합니다. 다른 차원(행성 또는 집)의 스테이션 슈트도 "다른 차원 · 원격 전용"으로 나와서 차원을 넘어 접속할 수 있습니다. 이디스 안경이 있어야 하고, 슈트를 입지 않은 상태에서 풀세트에 전력이 남은 슈트만 됩니다.
- 스테이션 슈트는 거리와 상관없이 그 스테이션 위에서 바로 깨어납니다. 동료는 있던 자리에서 그대로 조종합니다.
- 내 몸은 그 자리에 무방비로 남고, 주변 몬스터가 노립니다. **몸이 공격받으면 즉시 링크가 끊기고 몸으로 돌아와 그 피해를 받습니다.** 다른 동료 슈트들은 그동안 몸을 지킵니다.
- 원격 중에는 체력 대신 슈트 내구도가 닳습니다. 블록 설치, 아이템 사용, 차원 이동은 할 수 없습니다.
- **블록 파괴는 됩니다.** 부순 블록의 드롭과 원격 중에 주운 아이템은 내 인벤토리가 아니라 그 슈트 스테이션 옆의 **스테이션 창고**로 보내집니다. 창고가 없거나 꽉 차면 바닥에 남습니다.
- `G` 짧게: 연결 해제. 슈트가 몸 근처(96칸)에 있고 멀쩡하면 동료로 남고, 아니면 스테이션으로 귀환합니다. `G` 길게: 슈트도 귀환합니다.
- 내구도가 한계에 닿거나 전력이 바닥나도 링크가 끊깁니다.

### 동료 슈트

입고 있던 슈트에서 걸어 나오면, 빈 슈트가 혼자 움직이는 동료가 됩니다. 파츠는 실제 아이템 그대로라 에너지와 내구도가 이어집니다.

- 다시 입을 때는 동료가 내 앞에 등을 지고 서서 열리고, 내가 걸어 들어가면 닫힙니다.
- 주인 옆에 서서 대기하고, 주인이 6칸 넘게 멀어지면 다시 옆으로 날아옵니다. 아주 멀리 떨어지면 날아서 돌아옵니다.
- 주인을 때린 적, 주인이 때린 적, 주인을 노리는 몬스터를 공격합니다. **슈트마다 자기 기술을 씁니다**: Mark 1·50 리펄서·미사일·유니빔, Mark 2 냉동 빔·빙결 폭발, Mark 3 카드·순간이동·카드 부채(8장)·적이 많으면 템페스트, Mark 4 검·클로샷·회전 베기, Mark 5 3단 베기·버닝 어택·섬광 베기, Mark 44 땅에 내려와 주먹 연타·피스톤 펀치·지면 강타.
- 맞으면 체력 대신 파츠 내구도가 닳고, 한계에 닿으면 스스로 스테이션으로 수리하러 갑니다.
- 흉갑 전력으로 움직이고, 다 떨어지면 주저앉습니다 (직접 타거나 회수). 주인이 멀리 있으면 착지해서 전력을 아낍니다.
- 주인이 빈손으로 우클릭해도 탑승합니다.

### 내구도와 강제 이탈

- 슈트 파츠는 부서져 사라지지 않습니다. 내구도가 1 남으면 더 닳지 않습니다.
- 입고 있는 파츠가 한계에 닿으면 **강제 이탈**: 폭발과 함께 뒤로 튕겨 나가고, 슈트는 스테이션으로 돌아가 수리받습니다 (스테이션이 없으면 캡슐로).
- 손상된 슈트는 수리 전까지 호출·착용할 수 없습니다. 스테이션에 보관하거나 철 주괴로 모루에서 수리하세요.
- HUD의 `H C L B` 글자 색(청록 → 노랑 → 빨강)과 `장갑 %`로 내구도를 볼 수 있습니다.

### 헬멧 투시 HUD

헬멧을 쓰고 있으면 32칸 안의 적 몬스터에 벽 너머로도 조준 브래킷, 체력 바, 거리가 표시됩니다. 8칸 안의 적은 빨간색, 그 밖은 주황색입니다.

### 청소 로봇

로봇청소기처럼 지정한 구역을 돌며 적 몬스터를 지우고 떨어진 아이템을 빨아들입니다 (minebutler의 Guard Cleaner 이식).

1. **청소 로봇 도크**를 설치하고, **청소 로봇**을 도크에 사용합니다.
2. 도크를 **웅크리고 빈손 우클릭** → 바닥 모서리 블록들을 차례로 우클릭 → 첫 모서리를 다시 누르면 구역이 완성됩니다. 사각형이 아니어도 되며, 최대 64×64, 도크당 8개까지입니다. 막대기로 도크를 우클릭하면 구역이 전부 지워집니다.
3. 로봇은 아침·저녁 하루 2번 구역을 지그재그로 두 번 돌며 청소하고, 끝나면 도크로 돌아가 보관함에 비웁니다. 로봇을 우클릭하면 바로 청소를 시작합니다.

- 도크를 빈손으로 우클릭하면 보관함(27칸)과 상태가 열립니다.
- 청소 1회에 도크 전력 2,000 FE를 씁니다. 도크는 주변 전력 블록에서 충전됩니다.
- 도크나 로봇을 손에 들거나 이디스 안경을 쓰면 구역이 주황색 선으로 보입니다.
- 로봇을 웅크리고 우클릭하면 아이템으로 회수됩니다.

### 호버카

드래곤볼 캡슐 코퍼레이션 스타일의 떠다니는 차입니다.

- **호버카 캡슐**을 땅에 사용하면 차가 나오고, 웅크리고 빈손으로 우클릭하면 다시 캡슐로 들어갑니다.
- 우클릭으로 타고, W/S로 가속·브레이크, A/D로 회전합니다 (도는 방향 안쪽으로 차체가 기울어짐).
- 땅이나 물 위에 떠서 달리며, 4칸 높이까지 단차를 넘어갑니다.
- 전력은 움직일 때만 1 FE/틱을 써서 슈트 비행보다 훨씬 효율적입니다. 에너지 셀로 충전하거나 배터리·발전기·태양광 근처에 세워 두면 충전됩니다.

### 마을

바닐라 주민 마을이 아니라 **내 마을**입니다. 이름과 직업, 재능이 있는 주민을 받아들여 키우고 지킵니다.

**마을 회관**
- 놓으면 주변 가로세로 48칸(위아래 24칸)이 내 마을이 됩니다. 폭발에 부서지지 않습니다.
- 위에 선 **게시판**에 마을 수치가 적힙니다 (플레이어 화면이 아니라 건물에 적힘): 마을 단계, 인구(아이 수)와 직업별 인원, 교육, 식량 며칠분, 주거(침대), 행복, 안전, 건물, 공사 진행, 복구 대기·부족한 자재, 건축가의 건의, 경보, 최근 소식.
- 우클릭: **마을 창고** (54칸). 주민의 식량과 건축 자재를 넣습니다.
- 웅크리고 빈손 우클릭: 경보 해제.

**주민**
- **떠돌이**: 빈 침대가 있으면 아침마다(행복할수록 자주) 마을 가장자리에서 걸어옵니다. 말을 걸어 재능을 보고 **받아들이기 / 돌려보내기**를 고릅니다. 하루가 지나면 떠납니다.
- **직업**: 주민에게 말을 걸면 직업 12개 중 고를 수 있습니다. 같은 직업은 같은 옷이라 이름으로 구분합니다.
- **재능**: 직업마다 ★1~5. 대부분 ★1~3이고 한두 직업만 ★4~5입니다. 농부·건축가는 일 속도 60%~140%, 경비병·병사는 별마다 체력 +2칸, 공격력 +1.
- **하루**: 아침에 창고에서 한 사람당 음식 1개 (굶으면 기분 하락), 밤에는 자기 침대에서 잠.
- **쓰러짐**: 체력이 다하면 쓰러지고, 60초 안에 **음식을 들고 우클릭**(응급처치)하거나 **의사**가 치료하지 않으면 영구 사망합니다.
- **아이**: 아침마다 기분 좋은 어른 둘 사이에 아이가 태어날 수 있습니다 (어른 2명 이상, 빈 침대, 식량 여유, 행복 55 이상, 아이는 어른의 절반까지. 행복할수록, 의사가 있으면 더 자주). 아이는 작고 일하지 않으며 5일 뒤 어른이 됩니다.
- **교육**: 아이는 처음에 재능이 낮고 **관심 있는 일** 하나만 조금 높습니다. **학교**와 **선생님**이 있으면 매일 수업을 받고(선생님 한 명당 아이 4명), 어른이 될 때 배운 만큼 재능 ★이 오릅니다 (선생님 ★이 높을수록, 관심 있는 일이 더 잘 오름). 어른이 되면 무직으로 시작합니다.

| 직업 | 하는 일 |
|---|---|
| 농부 | 마을 안 농지와 건축가가 지은 밭을 돌며 수확하고 다시 심어 창고로 (밀은 빵으로). 씨앗이 없으면 풀을 베어 모음 |
| 건축가 | 부서진 블록 복구, 주문받은 건물 건설 (아래) |
| 경비병 | 낮에는 마을 곳곳, 밤에는 회관 근처를 순찰하며 마을 안 몬스터와 싸움. 싸울 상대가 없으면 마을의 불을 끔 |
| 병사 | 숨지 않고 싸움. 경보가 울리면 적이 나타난 곳으로 달려감 (원정·침략은 나중에). 항복한 적 병사를 등용하면 병사 주민이 됨 |
| 선생님 | 낮(수업 시간)에 학교 교탁 앞에서 수업. 아이들의 재능을 키움 |
| 의사 | 쓰러진 주민에게 달려가 치료해 일으킴 (경보 중에도, 재능이 높을수록 빠름). 다친 주민을 틈틈이 치료. 있으면 아이가 더 자주 태어남 |
| 상인 | 매일 아침 장에 나가 남는 식량(4일치는 남김)을 팔아 건축가에게 모자란 자재를 사 옴 (없으면 에메랄드) |
| 요리사 | 밀 → 빵, 날고기·생선 → 익힌 것, 감자 → 구운 감자. 따뜻한 밥을 먹은 날 모두 기분 +8 |
| 대장장이 | 원광석·조약돌·모래를 녹이고, 유리판이 모자라면 만듦. 경비병·병사 공격력 +0.5×★ |
| 목축업자 | 마을의 소·양·돼지·닭을 먹이로 번식, 달걀·양털 수확, 너무 많으면 고기로 |
| 악사 | 저녁마다 무대(없으면 회관 앞)에서 연주 → 다음 날 아침 모두 기분 상승 |

- 요리사·대장장이·목축업자·상인·악사는 매일 아침 일을 처리하고(별이 많을수록, 작업장이 있으면 더), 주민 화면 "지금:"에 어제 한 일이 나옵니다.
- **작업장**: 그 직업 주민이 있으면 건축가가 작업장을 건의합니다 - 주방, 대장간, 가게, 목장 우리, 진료소, 무대, 건축 작업장. 낮에는 그 주민이 작업장에서 일합니다.
- **집·밭의 주인**: 집은 그곳에서 자는 첫 어른이 주인("철수네 천막", 한 가구 한 집), 밭은 농부 한 명씩. 주민 화면에 "집:", "일터:"가 나옵니다.
- **건축가 상태**: 건축가를 클릭하면 "지금: 집 짓는 중 (12/86) · 자재 부족: 조약돌 12개"처럼 하는 일이 보입니다. 밭을 지을 때는 물을 먼저 놓습니다.

**경보**: 경비병이 마을 안 몬스터를 보거나, 주민이 몬스터에게 맞거나, 망루가 지상의 적을 발견하면 울립니다. 근처 종이 울리고 싸우지 않는 주민은 집이나 회관으로 대피합니다. 마지막 발견 30초 뒤 저절로 풀립니다. 적대 몬스터는 우리 주민도 노리고, 내 슈트 무기와 동료 슈트는 주민을 다치게 하지 않습니다.

**건축 (건의 + 설계도)**
- 건축가는 스스로 짓지 않고 **건의**합니다. 건축가에게 말을 걸어 **[건축] 탭**에서 건의 승인, 설계도 받기, 공사 확인·취소를 합니다.
- **설계도**를 들면 바라보는 땅에 건물 윤곽이 보입니다 (초록 = 빈 땅, 주황 = 밀어 내고 지음, 빨강 = 불가, 흰 상자 = 문 방향). 우클릭으로 자리를 잡고 같은 곳을 한 번 더 누르면 주문, 웅크리고 우클릭하면 회전합니다. 쓰면 없어집니다.
- 자리에 있던 나무·흙·구조물은 위에서부터 치우고 짓습니다 (치운 블록은 창고로). 자재는 창고에서 쓰고, 모자라면 그 층에서 기다립니다. 주인이 크리에이티브면 무료입니다.
- 한 건물에 건축가 최대 4명이 각자 4분의 1씩 맡습니다.
- 마을 안에서 폭발(크리퍼, 내 미사일 등)로 부서진 블록은 기록되어 건축가가 원래대로 되돌립니다 (직접 불 붙인 TNT 제외).

**마을 단계와 건물**

| 단계 | 조건 | 건물 |
|---|---|---|
| 1 유목민 캠프 | 시작 | 지휘 천막 (회관 건물), 천막 숙소 (침대 2), 통나무 망루, 밭 (9×9), 야외 학당 (7×7 정자: 긴 의자, 칠판, 교탁), 직업별 작업장 |
| 2 마을 | 인구 6명 + 회관 증축 (지휘 천막 → 석조 회관 개축) | 석조 회관, 나무집 (침대 4), **학교 건물** (야외 학당 개축) |
| 3 신도시 | 인구 15명 + **시청** (석조 회관 개축: 흰 콘크리트·유리 2층 로비, 11×11) | **아파트** (나무집 개축: 같은 자리에 2층 8침대, 큰 창, 평지붕) |

- 회관 건물은 회관 블록을 둘러싸고, 게시판은 안에서 보입니다.
- 다음 단계 건물이 열리면 옛 건물을 같은 자리에서 **개축**할 수 있습니다 (천막 숙소 → 집). 건의를 승인한 건물만 바뀝니다.
- 망루가 있고 경비병이 있으면 마을에 들어온 지상의 적을 바로 발견합니다.

### 삼국지 습격

위·촉·오 세 나라가 며칠마다 내 마을로 군대를 보냅니다. 사이가 좋은 나라(관계 30 이상)는 쳐들어오지 않습니다.

- **척후 보고**: 습격 날 오후에 "오늘 해질녘 ○군이 쳐들어온다"는 보고가 옵니다. 첫 습격은 마을을 세우고 사흘쯤 뒤, 그 뒤로는 4~8일마다입니다. 주민이 2명 미만이면 미뤄집니다.
- **3웨이브**: 해질녘 마을 바깥에 진을 치고 몰려옵니다. 앞 부대가 거의 무너지거나 1분이 지나면 다음 부대가 옵니다.
  1. 선봉: 검병·창병
  2. 2진: 궁병이 섞임. **화공**이면 불화살을 쏘아 마을에 불이 붙습니다 (경비병이 끄러 가고, 탄 블록은 건축가가 복구)
  3. 본대: **장수**가 호위병과 함께 직접 나섭니다 (보스 체력 바)
- 병사는 주민, 플레이어, 동료 슈트, 아군 장수를 노리고, 상대가 없으면 회관으로 진군합니다.
- **항전 의지**: 부대마다 랜덤입니다 (결사항전 / 보통 / 오합지졸). 일정 비율이 쓰러지거나 장수가 꺾이면 남은 병력이 **항복**해 무릎을 꿇습니다. 채팅의 **[등용하기]**를 누르면 병사는 우리 마을 **병사 주민**, 장수는 마을을 지키는 **아군 장수**가 됩니다. **[돌려보내기]**는 풀어 주고 그 나라와 관계가 좋아집니다. 3분 안에 고르지 않으면 돌려보냅니다.
- 끝까지 싸워 전멸시키면 전리품(**오수전**·철·빵·화살)이 마을 창고로 들어갑니다. 습격병을 쓰러뜨리면 가끔 오수전을 떨어뜨립니다. 반나절 안에 끝나지 않으면 적이 물러가며 창고를 조금 약탈합니다.
- 습격 중에는 내가 멀리 있거나 다른 차원에 있어도 **마을 청크가 로드되어 실제로 싸움이 일어납니다.**

| 장수 | 나라 | 기술 |
|---|---|---|
| 관우 | 촉 | 청룡언월도 회전베기. **일기토**: 처음 본 플레이어에게 일대일을 청하고, 병사들은 그 플레이어를 관우에게 맡김. 관우가 일기토에서 지면 군대 전체가 항복 |
| 장비 | 촉 | **장판교 고함**: 주변을 기절(둔화·나약함)시키고 마을의 유리·문을 깨뜨림 (건축가가 복구). 장팔사모 돌진 |
| 하후돈 | 위 | 돌진. 체력이 절반 아래로 떨어지면 분노해 공격력 1.5배 |
| 감녕 | 오 | 기습 (연기와 함께 대상 뒤로 이동해 벰), 회전베기 |

- 장수는 죽지 않고 쓰러지면 무릎을 꿇습니다. 등용한 장수는 병사처럼 마을 전체(48칸)를 맡습니다: 평소에는 마을 안을 순찰하고, 경보가 울리면 마을과 그 바깥 16칸 안의 가장 가까운 적에게 직접 달려갑니다 (주민과 함께 숨지 않음). 쓰러져도 1분 뒤 다시 일어납니다. 우클릭하면 인사합니다.

**이디스 경고**: 이디스 안경을 쓰거나 가지고 있거나 슈트 헬멧을 쓰고 있으면, 척후 보고·습격 시작·각 웨이브·항복·결과와 내가 마을에서 멀리 있을 때의 경보가 화면 위 경고창으로 뜹니다 (경고음, 거리·방향, 다른 차원이면 그 차원 이름). 채팅에도 남습니다. 경고를 받으면 슈트 휠의 원격 조종으로 마을 스테이션의 슈트에 접속해 막을 수 있습니다 (지금은 같은 차원만).

### 삼국지 성채와 외교

월드 스폰에서 600~850칸쯤 떨어진 곳에 위·촉·오의 **성채**가 하나씩 있습니다 (세 방향으로 나뉨). 처음 가까이 가면 그 자리에 지어집니다.

- **찾기**: `/village list`로 각 성채의 소문(대략의 방향·거리)을 볼 수 있습니다. 112칸 안에 들어가면 발견되고, 그 뒤로는 정확한 거리·방향과 관계가 나옵니다.
- **성채**: 81×81 성곽 도시입니다. 문루가 선 성문 4개, 모서리·성벽 중간 망루, 북쪽 궁궐 구역(낮은 담과 안뜰, 기단 위 궁궐, 단상의 왕좌에 앉은 **지도자** 유비·조조·손권 - 공격받으면 일어나 싸우고 조용해지면 다시 앉음), 광장의 종루, 병영 4채, 훈련장과 활터, 민가와 밭, 시장, 보급품 상자가 있는 곡물 창고, 마구간. 수비대 병사 12명과 그 나라 장수들이 성 안을 돌며 지킵니다 (가까이 있을 때만 있고, 떠나면 사라졌다가 다시 오면 채워짐). 예전의 작은 성채는 가까이 가면 새 설계로 다시 지어집니다.
- **관계** (나라마다, -100~100): 적대(-50 이하, 보면 공격) / 경계 / 중립 / 우호(30 이상, 내 마을을 습격하지 않음) / 동맹(70 이상). 수비대를 때리면 -3, 죽이면 -10. 음수는 하루에 1씩 회복됩니다.
- **장수의 무기**: 관우 청룡언월도, 장비 장팔사모, 하후돈 박도, 감녕 방울 곡도, 유비 쌍고검, 조조 의천검, 손권 고정도 (입체 모델).
- **성채 마을 사람 14명**: 농부(밭), 상인 3명(시장 노점: 곡물상·무기상·특산품 상인), 대장장이, 요리사, 원로, 아이. 낮에는 일터, 저녁에는 광장, 밤에는 집. 습격 중에는 숨습니다.
  - **상인 우클릭 = 거래** (바닐라 거래 화면, 돈은 **오수전**. 특산품 상인에게서 에메랄드 1 → 오수전 4로 환전, 오수전 6 → 에메랄드 1).
  - 다른 사람은 대화 + **부탁** (예: 농부 뼛가루, 대장장이 석탄): 그 물건을 들고 말을 걸면 오수전과 신뢰도 +2. 적대(-50 이하)면 말을 안 하고, 때리면 -5 (죽이면 -15).
- **지도자와 대화**: 궁궐의 지도자를 우클릭하면 관계, 진행 중인 의뢰와 버튼이 나옵니다. 다른 장수는 인사만 합니다.

**의뢰** (발견한 나라가 관계 0 이상이면 3일마다 하나. 채팅의 [수락] [거절], 하루 안에 답 안 하면 지나감)

| 의뢰 | 내용 | 성공 |
|---|---|---|
| 방어 지원 | 다음 날 해질녘 다른 나라 군대가 그 성채를 3웨이브로 침. 약속한 날 성채 근처(128칸)에 있으면 시작 | 모든 웨이브 격퇴 (관계 +15). 공격한 나라와는 -10 |
| 병력 파견 | 병사 주민 1~2명을 2~3일 빌려줌. 내 마을 안에서 [병사 보내기] | 기한이 지나 마을이 로드되면 돌아옴 (10% 확률로 한 명씩 전사). 관계 +12 |
| 침략 동행 | 이틀 뒤 해질녘 대상 성채 근처로 가면 요청한 나라의 군대 8명이 나타나 함께 공격. 대상 나라와는 즉시 적대 | 대상 성채 함락 (관계 +25) |

- 성공하면 오수전 16~32개와 금(침략은 다이아몬드도)을 받습니다. 거절 -5, 실패 -10. 지도자가 되면 매일 공물로 오수전 12~24개. 함락한 성채의 상자에도 오수전이 있습니다.

**성채 함락**: 성채의 병사·장수를 쓰러뜨리다 보면 그 성채의 항전 의지를 넘는 순간, 또는 지도자를 꺾는 순간 **항복**합니다. [등용하기]면 병사는 내 마을의 병사 주민, 장수는 아군 장수로 (다음에 마을이 로드될 때 도착, 지도자는 도망), [돌려보내기]면 관계 +15. 함락된 성채는 7일 동안 수비대 2명만 남고 장수가 없으며, 창고를 털 수 있습니다.

**내 군대 원정**: 내 마을 안에서 `/village army follow` → 마을의 병사 주민과 아군 장수가 따라다니며 싸웁니다 (멀어지면 따라잡음). `/village army home`으로 돌려보냅니다. 따라다니는 병사는 습격병, 나와 적대인 나라의 수비대, 근처 몬스터와 싸웁니다.

**동맹과 지도자**
- 동맹(70 이상)이면 지도자 대화의 **[지원군 요청]**: 그 나라 병사 3명이 하루 동안 따라다닙니다 (3일에 한 번).
- 관계 100 + 의뢰 5회 성공이면 **[지도자 추대 받기]**로 그 나라의 지도자가 됩니다: 매일 공물, 지원군 6명(하루에 한 번), 다른 나라 성채 근처에서 **[침략 명령]** (그 나라 군대가 함께 공격). 관계가 50 아래로 떨어지면 지도자 자리를 잃습니다.
- 삼국지 습격(M10)의 장수는 그 나라 성채에 "있는" 장수 중에서 나옵니다. 등용한 장수, 패해서 쉬고 있는 장수(3일)는 습격에 나오지 않습니다. 습격 군대는 그 나라 성채 방향에서 옵니다.

### 히어로 시티

스폰에서 950~1,150칸쯤, 두 성채 사이 방향에 매우 발전한 도시 **히어로 시티**가 하나 있습니다. 처음 가까이 가면 그 자리에 지어집니다. `/village list`에 소문(대략의 방향·거리)이 나오고, 128칸 안에 들어가면 발견됩니다 (이디스 알림).

- **도시**: 121×121. 가운데 광장에 50칸 **본부 타워**(유리 띠, 남쪽 면의 금색 A, 옥상 착륙장, 로비 안쪽에 금고 상자 2개와 신호기), 7칸 대로 2개와 격자 도로, 유리 고층 빌딩 4동, 유리 돔 과학관, 연못과 분수가 있는 중앙 공원, 성벽 쪽 낮은 건물들, 가로등, 낮은 석영 담. 예전의 작은 도시는 가까이 가면 새 설계로 다시 지어집니다.
- **히어로 7명**: 캡틴(지도자, 방패 던지기·주변 히어로 강화), 아이언맨(리펄서 사격), 토르(묠니르, 번개), 헐크(1.6배 덩치, 내려찍기), 스파이더맨(거미줄로 묶기), 블랙 위도우(전기 충격 근접), 호크아이(활, 4발마다 3발 동시). 쉴드 요원 6명이 도시를 지킵니다. 근처 몬스터와 악당, 히어로 시티와 적대인 플레이어(와 그 슈트·병사)와 싸웁니다.
- **무기**: 캡틴 원형 방패(왼손), 토르 묠니르, 위도우 진압봉 두 개, 호크아이 리커브 활, 요원 권총(두 손 조준으로 쏨).
- **시민 21명**: 회사원(빌딩), 과학자(유리 돔), 경찰(대로 순찰, 밤에도), 가게 주인 4명(전자제품점·식료품점·건축 자재점·첨단 기술점), 시민, 아이(공원). 가게 주인과 **거래**(돈은 **달러**, 첨단 기술점에서 에메랄드 1 → 5달러 환전), 다른 시민의 **부탁**을 들어주면 달러와 신뢰도. 치타우리 침공 중에는 집으로 숨습니다. 외곽 가게·집은 안이 꾸며져 있습니다.
- 히어로는 죽지 않습니다. 쓰러지면 물러나서 3일 쉬고 돌아옵니다. 가까이 있을 때만 있고, 떠나면 사라졌다가 다시 오면 채워집니다.
- **관계**: 삼국지 성채와 같은 단계 (적대 ≤-50 / 경계 / 중립 / 우호 ≥30 / 동맹 ≥70). 히어로를 때리면 -3, 쓰러뜨리면 -15. 적대가 되면 히어로들이 공격합니다.
- **캡틴과 대화** (우클릭): 관계와 받은 의뢰를 보여 주고, 의뢰 수락·거절 버튼이 나옵니다. 다른 히어로는 관계에 맞는 한마디를 합니다.

- 병력 파견: 병사 1~2명을 2일 동안. 내 마을 안에서 [병사 보내기] → 기한 뒤 마을이 로드되면 돌아옴 → +12.
- 성공하면 다이아몬드·에너지 셀 + 30~60달러, 거절 -5, 무응답 -3, 실패 -10. 함락한 도시의 금고에도 달러가 있습니다.

**침략**: 히어로 시티를 칠 수도 있습니다 (매우 어려움). 내가 직접, 또는 히어로 시티와 적대인 상태에서 내 슈트·병사가 쓰러뜨린 수가 12 이상(히어로 3, 요원 1로 셈, 5분 동안 더 쓰러뜨리지 않으면 초기화)이거나 캡틴을 꺾으면 **함락**: 히어로들이 7일 동안 물러나고 요원 1명만 남으며, 본부 로비의 금고(다이아몬드·아크 원자로·에너지 셀·네더라이트 조각, 함락 때마다 다시 채워짐)를 털 수 있습니다. 금고는 함락 전에는 열리지 않습니다. 관계는 -100이 됩니다.

### 배트맨 일당과 마을 보안

**배트맨·캣우먼·로빈**은 사는 곳 없이 떠도는 도둑입니다. 드물게 옵니다: 월드의 처음 5일은 오지 않고, 한 번 오면 그 뒤 5~15일 동안은 오지 않습니다. 밤(해가 지고 얼마 뒤)에 주민 2명 이상인 내 마을 하나를 골라 1~3명이 옵니다.

- **몰래**: 투명하게 웅크린 채 들어와 귀중품이 많은 상자부터 하나씩 찾아가 조금씩(묶음 절반씩) 훔치고, 빈칸에 **배트맨 표식**을 남깁니다. 헬멧 HUD에도 안 잡힙니다. 단서는 혼자 열렸다 닫히는 상자 뚜껑(통은 열림)과 작은 소리뿐입니다. 상자·통·스테이션 창고를 노리며, 캣우먼은 귀중품(다이아·에메랄드·금·철·네더라이트·아크 원자로·에너지 셀·마법 부여 아이템·슈트 등)만 가져갑니다.
- **발견하는 방법** (마을 보안): 밤에 깨어 있는 **경비병**(어두우면 6칸, 밝은 곳이면 14칸), 가까이 있는 **플레이어**(어두우면 3칸, 밝으면 8칸), 전력이 들어온 **보안 센서**(8칸). 때려도 들킵니다. 조명이 많을수록 잘 들킵니다.
- **들키면**: 마을 경보가 울리고(멀리 있으면 이디스 경고) 경비병·병사가 달려듭니다. 배트맨은 연막(주변 6칸 실명) + **EMP**(주변 8칸 전력 블록 방전 → 스테이션 창고 잠금 풀림, 12칸 안 슈트 에너지 30% 감소) 후 도주, 캣우먼은 빨라져서 도주, 로빈은 10초 싸우다 도주. 마을 밖으로 나가면 훔친 것과 함께 사라집니다.
- **잡으면**: 죽지 않고 훔친 물건을 전부 떨어뜨리고 연기 속으로 사라지며, 장비를 하나 남깁니다: 배트맨 → **배트랭**, 캣우먼 → **갈고리 총**, 로빈 → **연막탄** 3개.
- **스테이션 창고**는 전력이 있는 동안 잠겨 있어 배트맨만 열 수 있습니다 (조용한 EMP, 16칸 안의 깨어 있는 경비병이 들으면 들킴).
- **자거나 멀리 있으면**: 그 밤은 계산으로 처리됩니다 (오는 밤은 해 질 녘에 정해지므로 일찍 자도 피할 수 없음). 실제로 들어온 일당은 새벽까지 훔친 것만 가져갑니다. 경비병 1명당 12%, 켜진 보안 센서 1개당 25% (최대 85%) 확률로 쫓아내고(남기고 간 장비가 회관 창고에), 아니면 상자 몇 개가 털립니다. 결과는 회관 게시판 소식과 채팅으로 알려 주고, 마을이 로드되어 있지 않았으면 다음에 돌아갔을 때 반영됩니다 (그 전에 이디스가 "누군가 다녀간 흔적"을 알림).

### 우주선과 행성

**발사대**(새 블록)를 전력망에 연결해 충전하고(버퍼 120,000 FE, 초당 최대 40,000 FE 받음) 우클릭하면 갈 수 있는 행성이 나옵니다. **[○○로 발사]**를 누르면 100,000 FE를 쓰고(왕복 요금) 캡슐 코퍼레이션 우주선이 나타나 나를 태우고 이륙합니다. 7초쯤 올라가면 화면이 별이 흐르는 우주로 바뀌고, 그 사이 행성으로 건너가 하늘에서 천천히 내려앉습니다. 비행 중에는 내릴 수 없습니다.

- **행성 = 차원**: **드래곤볼 지구**, **나메크성**(드래곤볼 1장을 깨고 부르마와 이야기하면 발사대 목록에 나옴), **타이탄**. 사바나·평원·악지·사막·초원이 바둑판처럼 이어진 넓은 오픈 월드입니다 (시간은 지구와 같이 흐름).
- **착륙한 우주선이 거점**: 우클릭 → **[귀환]** (타고 집의 발사대로 돌아옴, 발사대가 없어졌으면 월드 스폰으로), **[원격 접속]** (집의 메인 스테이션에 있는 슈트에 차원을 넘어 원격 접속, 몸은 행성에 남고 주변 청크는 계속 로드). 다른 사람의 우주선은 쓸 수 없습니다.
- 행성에 있는 동안에도 마을이 습격당하거나 경보가 울리면 이디스가 알려 줍니다.
- 레시피: 발사대 = 철 블록 5, 아크 원자로, 배터리 2, 레드스톤 블록

**드래곤볼 지구 - 1장 사이어인 편** (`/planet`으로 지금 목표와 방향·거리를 볼 수 있음)

- **볼거리**: 착륙 지점 동쪽 가까이 **캡슐 코퍼레이션**(흰 돔, 부르마)과 그 둘레의 **서쪽 도시**(M17: 북·동·남으로 뻗은 대로, 돔 집 8채, 가게 3채 - 캡슐 코퍼레이션 상점·빵집·수련용품점, 공원, 가로등, 시민 10명. 돈은 **제니**, 에메랄드 1 = 5제니. 서쪽은 우주선 착륙장이라 비어 있음), 남서쪽 약 190칸 해변의 **거북하우스**(분홍 집, 야자수, 손오공), 북동쪽 약 220칸의 **라데츠가 떨어진 크레이터**(사이어인 포드). 가까이 가면 그 자리에 지어집니다.

- **싸움**: 인물마다 3단 콤보(타격 멈춤), 보스는 가드·잔상 회피, 격돌, 날아가는 기탄, 변신 연출(빛기둥·땅 균열·화면 흔들림). 라데츠 기탄·순간 돌진, 내파 주변 폭발, 베지터 갤릭포, 피콜로 마관광살포, 크리링 기원참, 천진반 태양권, 손오공 에네르기파, 재배맨 자폭. 보스와 아군은 죽지 않고 물러납니다. 팬텀 Mark 3는 이 기술들을 훔칠 수 있습니다.
- **장면이 끝나면** 함께 싸운 아군이 한동안 나를 따라다닙니다 (멀면 날아옴, 96칸 넘게 떨어지면 돌아감).
- **밤의 황무지**: 캡슐 코퍼레이션·거북하우스 근처가 아니면 밤에 재배맨이 1~2마리씩 나타납니다.
- **드래곤볼 7개**: 착륙 지점에서 80~320칸 떨어진 곳곳에 하나씩 (96칸 안으로 가면 땅 위에 나타나고, 그 위로 **주황 빛기둥**이 서서 200칸 밖에서도 보임. 부술 수 없고 우클릭으로 줍기). 부르마가 주는 **드래곤 레이더**를 들면 가장 가까운 공의 방향·거리가 나옵니다. 7개를 드래곤볼 지구 땅에 **4칸 안에 모아 놓으면** 3초 동안 빛이 솟고 천둥이 울린 뒤 **신룡**(마디 몸통 모델)이 솟아올라 2분 안에 소원 하나 (채팅 버튼): **강해지고 싶다** (최대 체력 +2칸, 최대 +6칸) / **더 강한 슈트** (입은 흉갑 배터리 업그레이드 3단계까지 - 아이언맨은 2단계까지) / **보물** (다이아 16, 네더라이트 주괴 2, 아크 원자로 3) / **선두콩** 6개. 그 뒤 공은 하늘로 흩어지고 3일 동안 돌이 됩니다. 떨어뜨린 드래곤볼은 사라지거나 타지 않습니다.

**컷신** (M17): 명장면 25개가 대본으로 연기됩니다. 화면 위아래 검은 띠와 자막, 카메라가 장면을 따라 움직이고, 그동안 나는 무적이고 주변 싸움은 멈춥니다. **점프 키로 건너뛰기** (건너뛰어도 끝 상태는 같음). 한 번 본 장면은 다시 나오지 않고, `/planet replay`로 본 목록, `/planet replay <id>`로 내 앞에서 다시 볼 수 있습니다 (이야기에 영향 없음). 인물·형태 40가지 (새로: 피콜로, 소년·청년 오반, 크리링, 야무치, 천진반, 야지로베, 미스터 사탄, 초사이어인 손오공, 거대원숭이 베지터, 최종 형태 프리저, 인조인간 16호, 불완전체·반완전체 셀, 악의 부우, 흡수 부우).

- "다음 날"은 해 뜰 때(게임 시간 0) 날짜가 바뀌는 기준입니다. 치트로 넘길 때는 `/time set`이 아니라 `/time add 24000`을 쓰세요 (`set`은 날짜를 되돌림).

### 타노스 사가

- **전조**: 20일째부터 (또는 누군가 드래곤볼 지구 1장을 깨면) 히어로 시티를 치는 치타우리가 더 많아지고(웨이브마다 8), 마지막 웨이브에 거구가 둘 나옵니다 (캡틴: "누군가 뒤에서 보내고 있다").
- **타이탄** (새 행성, 발사대에서 선택): 영원한 황혼 속의 붉은 황무지 (잠들 수 없음). 착륙 지점 근처에 타노스 고향의 폐허, 사방 약 260칸에 **블랙 오더**의 경기장 넷, 북서쪽에 **보르미르 첨탑**(사다리로 오름).
  - 에보니 모 → **스페이스 스톤** (염력: 띄웠다가 내리꽂기), 프록시마 미드나이트 → **리얼리티 스톤** (창, 돌진), 콜버스 글레이브 → **마인드 스톤** (등 뒤로 순간이동), 컬 옵시디언 → **파워 스톤** (1.4배 덩치, 땅 내려치기). 경기장 40칸 안에 그 스톤이 없는 사람이 오면 나타나고, 쓰러뜨리면 근처의 그 스톤 없는 사람 모두에게 스톤.
  - 보르미르 첨탑 꼭대기의 **레드 스컬**: "영혼에는 영혼" - 경험치 30레벨을 바치면 **소울 스톤**.
- **타임 스톤**: 히어로 시티. 동맹(70 이상)이면 캡틴 대화에 [타임 스톤] 버튼 (한 번), 아니면 히어로 시티를 함락시키면 금고에.
- `/planet`: 모은 스톤과 타이탄에서 다음 목표의 방향·거리. 스톤은 사라지거나 타지 않습니다.
- **최종전**: 스톤 3개를 얻으면 이틀 뒤 해 질 녘 타노스가 **내 마을**로 옵니다 (마을이 없으면 히어로 시티로). 이디스가 미리 알려 주고, 그동안 마을은 로드된 채로 진짜 전투가 벌어집니다.
  - 웨이브: 치타우리 8 → 블랙 오더 둘 + 치타우리 4 → **타노스** (1.35배, 체력 1200). 타노스의 건틀렛에는 **내가 갖지 못한 스톤**이 모두 끼워져 있습니다: 파워(강한 내려치기·기탄) / 스페이스(눈앞으로 순간이동) / 리얼리티(실명·멀미) / 타임(체력이 줄면 한 번 되감기) / 마인드(둔화·나약) / 소울(때릴 때마다 회복). 스톤을 많이 모을수록 그가 약해집니다.
  - 히어로 시티와 동맹(70 이상)이면 캡틴·아이언맨·토르·헐크가 마을로 와서 함께 싸웁니다 ("어벤져스, 어셈블!").
  - **이기면** (타노스를 쓰러뜨림): **나노텍 Mark 50** 슈트 캡슐 (가장 튼튼한 장갑, 입고 있으면 나노 입자가 2초마다 내구도를 고치고 흉갑을 충전). 타노스는 다시 오지 않습니다.
  - **10분을 버티지 못하면**: 타노스가 손가락을 튕겨 주민 절반이 재가 되어 사라집니다. **저절로 돌아오지 않습니다** (엔드게임처럼): 타노스를 다시 맞아 이기거나 인피니티 건틀렛으로 스냅하면 모두 돌아옵니다 (마을이 다음에 로드될 때 회관 곁에서 주황빛 먼지가 모여 사람이 됨). 5일 뒤 다시 옵니다.
- **인피니티 건틀렛** (금 블록 5, 네더라이트 주괴, 다이아몬드 블록): 우클릭으로 가진 스톤을 끼움. 여섯 개가 다 차면 우클릭 = **스냅**: 96칸 안의 타노스 군단은 재가 되고 (타노스도 → 승리), 48칸 안의 몬스터가 쓰러집니다. 대가: 체력 반 칸만 남고 배고픔 0, 나약함 2분, 스톤은 타 버림 (한 번뿐).

### 테스트 명령어 (치트 필요)

- `/flightsuit durability <0-100>`: 입은 슈트와 16칸 안의 내 동료 슈트의 내구도를 %로 설정합니다. `0`이면 다음 피격에 강제 이탈합니다.
- `/flightsuit energy <0-100>`: 에너지를 %로 설정합니다.
- `/flightsuit village wanderer`: 서 있는 마을에 떠돌이를 바로 부릅니다 (빈 침대가 없어도 됨). 크리에이티브 탭의 떠돌이 생성 알도 같은 역할입니다.
- `/flightsuit village birth`: 서 있는 마을에 아이를 바로 태어나게 합니다. `/flightsuit village grow`: 그 마을의 아이들을 바로 어른으로 키웁니다.
- `/flightsuit raid start [wei|shu|wu]`: 서 있는 마을에 습격을 바로 시작합니다. `/flightsuit raid stop`: 습격을 끝내고 적을 치웁니다.
- `/flightsuit fort tp <wei|shu|wu>`: 그 성채 앞으로 순간이동 (처음이면 그때 지어짐). `/flightsuit fort rebuild <나라>`: 다음에 가까이 가면 같은 자리에 새 설계로 다시 지음. `/flightsuit fort trust <나라> <-100~100>`: 관계 설정. `/flightsuit fort done <나라> <횟수>`: 의뢰 성공 횟수 설정. `/flightsuit fort request <나라> <defend|reinforce|invade>`: 그 나라가 지금 의뢰를 보냄 (오늘 해질녘 기준)
- `/flightsuit hero tp`: 히어로 시티 앞으로 순간이동 (처음이면 그때 지어짐). `/flightsuit hero rebuild`: 다음에 가까이 가면 같은 자리에 새 설계로 다시 지음. `/flightsuit hero trust <-100~100>`: 히어로 시티와의 관계 설정. `/flightsuit hero request <defend|reinforce>`: 캡틴이 지금 의뢰를 보냄 (오늘 해질녘 기준)
- `/flightsuit thief now`: 서 있는 마을에 오늘 밤 배트맨 일당이 옴 (시간이 밤으로 바뀜). `/flightsuit thief spawn <batman|catwoman|robin>`: 숨은 도둑 하나를 눈앞에. `/flightsuit thief when`: 다음 방문 날
- `/flightsuit dbz stage <단계>`: 드래곤볼 이야기 단계를 바로 바꿈 ("다음 날" 기다림도 풀림). 단계: `arrived, met_bulma, met_goku, raditz_beaten, nappa_beaten, saiyans_beaten, namek_open, met_dende, zarbon_beaten, ginyu_beaten, frieza_beaten, met_trunks, androids_beaten, cell_beaten, buu_beaten, kid_buu_beaten`. `/flightsuit dbz cutscene <id>`: 컷신을 내 앞에서 바로 봄 (본 적 없어도). `/flightsuit dbz stop`: 지금 행성의 이야기 전투를 끝냄 (보상 없음)
- `/flightsuit dragonballs give`: 드래곤볼 7개를 바로 받기. `/flightsuit dragonballs reset`: 드래곤볼을 다시 흩기 (돌 상태도 풀림)
- `/flightsuit thanos now`: 타노스가 지금 내 마을로 옴. `/flightsuit thanos stones`: 인피니티 스톤 6개 받기
- `/flightsuit raid general <guan_yu|zhang_fei|xiahou_dun|gan_ning|liu_bei|cao_cao|sun_quan>`: 눈앞에 적 장수를 부릅니다. 크리에이티브 탭의 삼국지 병사·장수 생성 알도 있습니다.

### 이디스 안경

머리 슬롯에 쓰는 안경입니다. 슈트를 입으면 인벤토리로 들어가고, 슈트가 귀환하면 다시 씁니다. 안경만 쓰고 있을 때는 지휘용 HUD(시간, 좌표, 메인 슈트 충전량, 스테이션 거리·전력)가 보입니다.

### 스테이션과 전력

| 블록 | 역할 |
|---|---|
| 슈트 스테이션 | 설치하면 3×3, 높이 4칸의 갠트리로 펼쳐집니다 (발판, 뒤 기둥 2개, 천장 빔, 로봇 팔 5개). 슈트 1벌 보관(위에 서 있는 모습), 충전, 내구도 수리, 로봇 팔 착용·해제. 우클릭하면 메인 스테이션으로 지정 |
| 태양광 패널 | 낮에 하늘이 보이면 30 FE/t (비 오면 30%) |
| 발전기 | 화로 연료를 태워 60 FE/t. 연료를 들고 우클릭해서 넣음 |
| 배터리 | 1,000,000 FE 저장 |
| 스테이션 창고 | 54칸 창고. 반경 8칸 안의 슈트 스테이션과 자동으로 짝지어져, 원격 조종 중 줍거나 부순 아이템이 여기로 옴. 전력이 있으면 잠김 (2 FE/t, 나중에 도둑 대비). 웅크리고 빈손 우클릭 = 정렬 |

반경 8칸 안의 전력 블록은 선 없이 자동으로 연결됩니다 (생산 → 스테이션 우선 → 배터리, 배터리 → 스테이션). Forge Energy 규격이라 다른 모드의 케이블과도 연결됩니다. 블록을 우클릭하면 상태가 표시됩니다.

### 파츠별 효과

파츠 하나만 입어도 그 파츠의 기능을 쓸 수 있습니다.

| 파츠 | 효과 |
|---|---|
| 헬멧 | 야간 투시 |
| 흉갑 | 빈손 우클릭으로 주무기, `X`/`C`로 스킬 (슈트 종류별). 슈트 전체의 배터리(아크 리액터) |
| 레깅스 | 이동 속도 +20%, 1칸 단차 오르기, 낙하 피해 절반 |

| 풀세트 | 스페이스 2번으로 비행(호버링). 달리기 + 앞으로 = 고속 비행. 낙하 피해 없음 |

### 에너지

- 흉갑을 입고 있으면 흉갑 배터리(20,000 FE)를 모든 파츠가 함께 씁니다. 흉갑이 없으면 각 파츠의 작은 내장 배터리만 씁니다.
- 스테이션에 보관하면 충전되고, 밖에서는 **에너지 셀**을 우클릭해 착용한 슈트를 충전할 수 있습니다.
- 크리에이티브 모드에서는 에너지가 줄지 않습니다.

외형은 아직 모델링 전입니다. 슈트는 64×64 플레이어 스킨 형식 이미지를 파츠별로 잘라 쓰고, 블록과 안경은 코드로 그린 임시 텍스처입니다. 다시 생성하려면:

```bash
java tools/SuitSkinGen.java mk1 docs/reference/ryan_mk1_skin_source.png
java tools/SuitSkinGen.java mk2 docs/reference/ryan_mk2_skin_source.png
java tools/SuitSkinGen.java mk3 docs/reference/phantom_mk3_suit_skin.png
java tools/SuitSkinGen.java mk4 docs/reference/hero_mk4_suit_skin.png
java tools/SkinSplitter.java docs/reference/ryan_mk1_skin_source.png src/main/resources/assets/flightsuit/textures ryan_mk1
java tools/SkinSplitter.java docs/reference/ryan_mk2_skin_source.png src/main/resources/assets/flightsuit/textures ryan_mk2
java tools/SkinSplitter.java docs/reference/phantom_mk3_suit_skin.png src/main/resources/assets/flightsuit/textures phantom_mk3
java tools/SkinSplitter.java docs/reference/hero_mk4_suit_skin.png src/main/resources/assets/flightsuit/textures hero_mk4
java tools/TextureGen.java src/main/resources/assets/flightsuit/textures
java tools/ResidentSkinGen.java src/main/resources/assets/flightsuit/textures/entity/resident
java tools/FactionSkinGen.java src/main/resources/assets/flightsuit/textures/entity/kingdom
```
