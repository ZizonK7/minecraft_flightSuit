## 0. 환경과 작업 규칙

- **빌드가 안 됩니다.** 클라우드에서는 Forge·Mojang 메이븐이 막혀 `./gradlew build`가 실패합니다. 그러므로:
  - 기존 코드에 이미 쓰인 API 패턴을 그대로 따릅니다 (새 라이브러리 금지, GeckoLib 금지. 모델은 `tools/ModelGen.java` 방식의 자바 코드 모델).
  - 모든 자바 파일은 **JDK 파서로 문법 확인**을 합니다. 아래 `ParseOnly.java`를 스크래치패드에 만들어 `java ParseOnly.java <파일들>`로 돌립니다. 한 묶음을 끝낼 때마다 바뀐 파일 전부를 돌립니다.
  - 인게임 테스트는 사용자가 합니다. 모든 새 기능은 `DESIGN.md`에 "인게임 테스트 전"으로 표시합니다.
- **묶음(A→B→C→D)마다 커밋**합니다. 커밋 메시지는 영어 한 줄 요약 + 본문, 끝에 `Co-Authored-By: Claude ...` 줄. 한 묶음이 끝나기 전에는 다음 묶음에 손대지 않습니다. 시간이 다 되면 그 자리에서 끊고 **5장 "끝낼 때"**를 반드시 합니다 (문서 갱신이 코드보다 중요합니다. 사용자는 문서를 보고 테스트합니다).
- 우선순위: **A 슈트 3벌 → B 컷신 엔진·전투 모션 → C 드래곤볼 스토리 재구성 → D 마을**. D는 시간이 남을 때만.
- 코드 주석은 영어, 문서·대사·툴팁은 한국어(ko_kr)와 영어(en_us) 둘 다.
- `// <ModelGen:이름>` 블록은 손으로 고치지 않습니다 (`java tools/ModelGen.java . <이름>`으로 다시 생성).
- 1.20.1 goalSelector는 2틱에 한 번 돕니다. `canUse`에 `tickCount % N` 금지 (`CLAUDE.md` 참고).
- 새 아이템·기술은 `tip.flightsuit.<id>` 번역(ko/en)과 안내서(`client/GuideBook.PAGES`) 쪽을 넣습니다.

```java
// ParseOnly.java (스크래치패드에 저장; 저장소에 넣지 않음)
import javax.tools.*; import java.util.*; import java.nio.file.*;
import com.sun.source.util.JavacTask;
public class ParseOnly {
    public static void main(String[] a) throws Exception {
        JavaCompiler c = ToolProvider.getSystemJavaCompiler();
        StandardJavaFileManager fm = c.getStandardFileManager(null, null, null);
        List<Path> files = new ArrayList<>();
        for (String s : a) try (var st = Files.walk(Path.of(s))) { st.filter(p -> p.toString().endsWith(".java")).forEach(files::add); }
        var task = (JavacTask) c.getTask(null, fm, d -> System.out.println(d), List.of("-proc:none"), null, fm.getJavaFileObjectsFromPaths(files));
        task.parse(); System.out.println("parsed " + files.size());
    }
}
```

#### A-3-2. 순간이동 개선 (`SuitSkills.stepTarget` / `startShadowStep`, `PhantomAimClient`)

지금은 "시선이 닿는 블록 바로 앞"뿐이라 위·아래·턱 위로 못 간다는 피드백. 아래 규칙으로 교체:

1. 거리 **40칸** (`SHADOW_STEP_RANGE`). 비용 = 100 + 거리×7.5 FE (40칸 = 400). 대기 1.5초 유지.
2. **몬스터를 보면** 그 등 뒤 1.5칸 (기존).
3. **블록을 보면**: 맞은 블록 **위에 설 수 있으면(2칸 공간) 그 위로** (턱·지붕 오르기). 안 되면 맞은 면 바로 앞 (기존). 윗면을 봤으면 그 지점.
4. **하늘을 보면(아무것도 안 맞음)**: 시선 끝 지점에서 **아래로 8칸까지 땅을 찾아** 있으면 그 위. 없으면 **공중 그 지점**으로 가서 `카드 발판` 1초 (움직임 고정, 카드 파티클 원) 뒤 느리게 낙하(`slow_falling` 2초). 위로 올라가는 문제를 이것으로 풀기.
5. **아래를 보면**: 구멍이면 바닥까지 (3·4의 규칙으로 자연히 처리되는지 확인).
6. **조준 중 마우스 휠**로 거리 ±2칸 조절 (`InputEvent.MouseScrollingEvent`에서 조준 중이면 소비). 원 표시가 그 거리에 맞춰 움직임. 하늘 조준에서 특히 유용.
7. 출발·도착 카드 소용돌이 0.5초, 클릭 확정은 그대로. 클라 미리보기(원 색: 보라/빨강)와 서버 결과가 같은 함수를 쓰게 유지.

#### A-3-3. V 궁극기: 템페스트 (하늘에서 카드 폭우)

- V 누르면 팬텀이 카드 한 장을 하늘로 던지는 모션(JSON `tempest_throw`) → 조준 지점(40칸 안, 없으면 자기 앞 10칸) 위 하늘이 보라색 입자로 물들고 **반경 10칸에 4초 동안 카드가 비처럼 내리꽂힘** (`card_swirl`·`CardRenderer` 재사용, 1틱 6~8장이 위 12칸에서 떨어져 땅에 박히고 흩어짐).
- 피해: 0.25초마다 범위 안 적 전원에게 3 (총 48), 맞는 동안 이동 속도 40% 감소, 비행 중인 적(`!onGround`)은 아래로 0.5 눌림. 보스도 그대로 피해.
- 끝에 카드가 전부 한 장으로 모여 손으로 돌아오는 파티클.
- **6,000 FE, 60초 대기**. 동료 팬텀은 반경 10칸 안에 적 5명 이상일 때 씀.

#### A-3-4. 바뀌지 않는 것

저지먼트 드로우(X)는 넷 + 조커 그대로(사용자: "패시브는 우선 이대로"). 카드 대결(C), 카르트 블랑슈·누아르 그대로. 날지 못함 그대로.

## 2. 묶음 B: 컷신 엔진 + 드래곤볼 전투 모션

### B-1. 컷신 엔진 (`cutscene/` 새 패키지)

연출을 장면마다 손으로 짜지 않고 **대본 데이터**로 돌립니다. C의 장면 20여 개는 모두 이 엔진의 대본입니다.

- **구조**: `Cutscene`(id, 샷 목록) → `Shot`(길이 틱, 카메라 시작·끝 위치와 바라보는 점(앵커 기준 상대 좌표, 이징), 자막 키, 배우 동작 목록, 소리, 파티클) → `ActorAction`(배우 id, 동작: `walk_to`, `fly_to`, `face`, `pose(동작 번호)`, `beam_at`, `knockback`, `fall`(쓰러짐), `transform`, `glow`, `vanish`, `appear`, `say`). 자바 열거형/레코드로 씁니다 (JSON 파서는 만들지 않음).
- **배우**: `DbzFighterEntity`를 **연기 모드**(새 EntityData `ACTING`)로 소환. 연기 모드에서는 AI·표적·피해 모두 꺼지고 서버가 위치·동작을 직접 움직임. 컷신이 끝나면 대본이 정한 대로 전투 인물로 바뀌거나(`ACTING` 해제, 이미 있는 전투 인물과 연결) 사라짐.
- **카메라**: 보이지 않는 `CameraEntity`(새 엔티티, 렌더러 없음, 저장 안 함)를 서버가 경로대로 옮기고 `ServerPlayer.setCamera(cameraEntity)`로 그 시점을 보게 함. 끝나면 `setCamera(player)`. 기존 `client/CinematicCamera`는 착용 연출용 3인칭 전환이라 그대로 두고, 컷신은 이 방식으로.
- **화면**: 새 `CutsceneS2CPacket`(시작: 대본 id·앵커 / 자막 바꿈 / 끝) → 클라 `CutsceneOverlay`가 위아래 검은 띠(화면 높이의 12%)와 자막(가운데 아래, 인물 이름 색 = `DbzCharacter.displayName` 색)을 그림. 컷신 중에는 HUD(슈트·목표 표시)를 숨김.
- **플레이어**: 컷신 중 이동·입력 무시(서버에서 위치 고정), 무적, 가까운 전투 인물(`DbzFighterEntity`)은 멈춤(`Fight`에 `paused` 플래그). 플레이어가 둘 이상이면 96칸 안의 모두에게 재생.
- **건너뛰기**: 스페이스(점프 키) → `CutsceneSkipC2SPacket` → 그 컷신의 **끝 상태로 즉시 점프**(배우 위치·생사·스토리 단계가 스킵해도 똑같아야 함. 대본의 각 샷에 "끝 상태"를 적용하는 코드가 따로 있어야 함).
- **한 번만**: 플레이어별로 본 컷신 id를 `PlanetData.traveller(uuid)`에 집합으로 저장. 다시 보기 `/planet replay <id>` (권한 없이, 그 자리에서 재생. 배우만 소환하고 스토리 상태는 안 바꿈).
- **재생 길이**: 한 컷신 10~25초. 배우 수 최대 8.

### B-2. 드래곤볼 인물 모션 (`client/DbzFighterModel` 새 모델)

지금은 `PlayerModel` + 바닐라 팔 흔들기뿐. "진짜 휘두르고 때리고 맞고"를 위해:

- `DbzFighterModel extends PlayerModel<DbzFighterEntity>` (또는 `ShiftedHumanoidModel` 방식)에 **코드 포즈**. 서버가 `ACTION`(바이트)·`ACTION_START`(틱) EntityData로 동기화, 클라가 경과 틱으로 보간.
- 동작 목록: `IDLE`, `FLY`(몸 앞으로 기울고 팔 뒤로), `PUNCH_L`, `PUNCH_R`, `KICK`, `GUARD`(팔 교차), `CHARGE`(두 손 옆구리, 몸 숙임), `FIRE`(두 손 앞으로 뻗기), `HURT`(상체 뒤로 꺾임), `DOWN`(쓰러져 누움), `TRANSFORM`(몸 떨림 + 팔 벌림), `POSE_GINYU`(특전대 포즈 5종은 번호 하나로, 인물별 분기), `HEADBUTT`(오반), `CARRY`(피콜로가 감싸는 자세).
- 체격: `DbzCharacter.scale`을 **모델과 히트박스 둘 다**에 적용 (지금 히트박스에만 적용 중인지 확인). 사용자 의견 "기뉴 같은 애들도 사람보다 크다"에 따라 수치 조정 (Claude 판단): 기뉴 1.15, 리쿰 1.3, 버터 1.2, 내파 1.3, 도도리아 1.3, 라데츠 1.1, 완전체 셀 1.2, 마인 부우 1.3, 악의 부우 1.15, 16호 1.25, 피콜로 1.1.
- **전투 규칙** (`DbzFighterEntity` 근접 공격 교체):
  - 근접은 **3타 콤보**(주먹·주먹·발차기, 0.3초 간격, 3타째 넉백 2배). 맞는 쪽은 `HURT` 포즈 + **타격 멈춤 3틱**(둘 다 잠깐 멈춤). 피해 소리는 바닐라 강타 + 짧은 파티클 `crit`.
  - 보스는 플레이어 빔을 맞으면 30% 확률로 **가드**(피해 절반, 가드 포즈), 15% 확률로 **회피 돌진**(옆으로 6칸 순간 이동에 가까운 가속 + 잔상).
  - **격돌**: 아군 인물과 보스가 6칸 안이면 10초마다 한 번, 둘이 공중으로 떠올라 1.5초 동안 서로 치고받는 연출(위치를 서버가 번갈아 밀어 줌, 번쩍이는 `flash` 파티클). 그동안 플레이어가 빔을 맞히면 격돌이 플레이어 쪽 승리로 끝나 보스가 `HURT`로 떨어짐.
  - 기술 연출: 충전 빔은 `CHARGE`→`FIRE` 포즈와 함께 **굵은 입자 기둥**(지름 1.5칸, 중심 흰색 + 바깥 기술 색), 명중 지점에 폭발 구(지름 4칸 입자). 기탄은 꼬리 파티클. 변신은 금빛 빛기둥 + 땅 균열 파티클 + 1초 화면 흔들림(카메라 흔들림은 클라에서 `CutsceneS2CPacket`의 shake 필드로).
- `DbzFighterRenderer`를 새 모델로 바꾸고, `ArmPose.BOW_AND_ARROW` 임시 조준 자세는 제거.

### C-2. 장면 흐름

구조는 그대로(장면 = 정해진 무대 + 웨이브, 96칸 밖·20분이면 리셋)이고, **웨이브 사이와 앞뒤에 컷신·대화·동행 이동**을 넣습니다. 각 컷신은 B-1 엔진의 대본 하나(id는 `dbz.<이름>`). 아래 "컷신" 표기는 사용자가 꼽은 명장면입니다. 모두 넣습니다.

**1장 사이어인 편** (지구, `DbzEarth` 크레이터)
1. 라데츠 등장 컷신(기존 후보: 포드 추락·스카우터) → 크레이터 전투: 라데츠 vs 플레이어 + 손오공 + **피콜로**. 라데츠 체력 50%에서 **컷신 `gohan_headbutt`**: 라데츠가 손오공을 깔고 앉은 순간 포드에서 소년 오반이 튀어나와 박치기, 라데츠가 비틀거림 → 전투 재개(라데츠 피해 1.3배 받음) → 라데츠 체력 10%에서 **컷신 `special_beam_cannon`**: 손오공이 뒤에서 붙잡고 피콜로의 마관광살포가 둘을 관통, 라데츠 "동료 둘이 1년 뒤에 온다" → 손오공·라데츠 사망. **손오공은 2장 기뉴 때까지 동행하지 않음**(원작처럼. Claude 판단, 확인 필요).
2. 다음 날 크레이터: 재배맨 6 웨이브, 아군 **피콜로·크리링·야무치·천진반·소년 오반**. 재배맨 마지막 하나가 남으면 **컷신 `yamcha_dies`**: 야무치가 쓰러진 재배맨에게 다가가다 자폭에 휘말려 사망.
3. 내파 웨이브 (아군은 야무치 빠짐). 내파 체력 30%에서 **컷신 `piccolo_dies`**: 내파의 빔이 오반을 향하고 피콜로가 감싸서 사망. 이후 오반 "피콜로 씨!"로 피해 1.5배 버프 10초.
4. 베지터 웨이브. 체력 70%에서 **컷신 `kaioken`**: 손오공이 돌아와(순간 이동 아님, 하늘에서 내려옴) 계왕권으로 베지터를 날림 → 손오공 동행 재개(붉은 오라, 피해 1.5배). 체력 40%에서 **컷신 `oozaru`**: 베지터가 가짜 달을 띄우고 거대원숭이로 변신 → 보스가 `OOZARU_VEGETA`로 교체(체력 900). 거대원숭이 체력 30%에서 **컷신 `tail_cut`**: 야지로베가 뒤에서 꼬리를 벰 → 다시 베지터(체력 150으로 고정). 쓰러지면 **컷신 `vegeta_spared`**: 손오공이 크리링을 막고 베지터가 포드로 기어가 떠남. 1장 클리어 보상 그대로 + 선두콩.

**2장 나메크성**
- 마을 방어(기존) → 기뉴 특전대(기존 포즈 컷신을 엔진 대본으로 옮김) 때 **손오공 복귀**(우주선 착륙 대사) → 프리저 전: 아군 손오공·피콜로·크리링·소년 오반. 프리저 체력 50%에서 변신(기존) 뒤, **컷신 `krillin_dies_ssj`**: 프리저가 크리링을 터뜨리고 손오공이 분노로 초사이어인(금빛 빛기둥, 머리 색 변화 = 스킨 교체, 가장 공을 들일 컷신. 샷을 길게, 15~20초) → 손오공 `GOKU_SSJ`로 교체, 피해 2배.
- 프리저 체력 15%에서 **멸망 페이즈**: 프리저가 행성 핵을 치는 컷신 `namek_dying` → 3분 제한(HUD 보스 바 아래 남은 시간), 하늘 번개 자주, 바닥에 균열 블록(마그마 블록·용암 2~3칸 구덩이)이 10초마다 무대 안에 생김. 시간 안에 못 끝내면 플레이어 사망 아닌 **실패 리셋**(96칸 밖 규칙과 같이 다음에 처음부터).
- 쓰러지면 **컷신 `namek_escape`**: 마지막 일격 뒤 손오공이 기뉴의 포드로 탈출, 플레이어는 우주선으로 자동 귀환 안내.

**3장 인조인간·셀**
- 트랭크스 등장(기존 후보 컷신) → 인조인간 전투에 아군 **16호** 추가 → 전투 끝에 **컷신 `cell_absorbs_17`**: 불완전체 셀이 나타나 17호를 꼬리로 흡수 → 반완전체 → 바로 이어 **컷신 `cell_absorbs_18`**: 18호를 흡수 → 완전체, "셀 게임을 연다" 선언. (사용자 확인: 흡수 장면은 17호·18호 둘.)
- 다음 날 셀 게임 링(기존) 주변에 **천하제일 무도회 분위기**: 관중석 블록에 `TownsfolkEntity`(관중 역할) 10명, 미스터 사탄·아나운서 대사 몇 줄, 깃발·횃불. 셀 주니어 웨이브(아군 손오공·트랭크스·청년 오반·피콜로·크리링·16호) → 셀 주니어 끝에 **컷신 `gohan_awakens`**: 셀이 16호를 부수고 오반이 초사이어인 2로 각성 → 오반 `GOHAN_TEEN_SSJ2`, 피해 2배. 셀 전 체력 20%에서 **컷신 `cell_self_destruct`**: 셀이 부풀고 손오공이 순간이동으로 데려감(둘 사라짐) → 10초 뒤 셀 재등장(체력 30%) → 쓰러지면 **컷신 `father_son_kamehameha`**: 오반의 한 손 에네르기파, 하늘에서 손오공 목소리, 셀 소멸. 보상 트랭크스 Mark 5(기존).

**4장 마인 부우**
- 뚱보 부우 전투(기존). 체력 30%에서 **컷신 `buu_befriends`**: 미스터 사탄이 나타나 부우와 친해짐, 부우가 아군이 됨 → `MAJIN_BUU`가 ALLY로 전환(체력 회복). 바로 **컷신 `super_buu`**: 악의 부우가 분리되어 뚱보 부우를 먹음 → 악의 부우 보스 전투(아군 손오공·청년 오반·피콜로·트랭크스). 체력 50%에서 **컷신 `buu_absorbs`**: 오반·피콜로가 끌려가 흡수, 아군에서 사라지고 보스 체력 1.3배·스킨 교체.
- 흡수 부우 쓰러지면 **컷신 `kid_buu`**: 흡수된 이들이 뱃속에서 빠져나오고 키드 부우가 남음 → 키드 부우 전(기존 원기옥) → **컷신 `spirit_bomb_end`**: 모든 마을 사람의 손이 올라가고 원기옥이 키드 부우를 지우며 스토리 끝. 엔딩 자막 몇 줄 + 보상.

### C-3. 장면 사이

- 각 장이 열릴 때 **부르마/덴데/트랭크스와의 대화**(기존 말 걸기)에 2~3줄 추가로 다음 목적지 설명. 길안내(`StoryGoalOverlay`)는 그대로.
- 전투 뒤 **동행 이동**: 아군 인물이 다음 무대로 플레이어와 함께 날아감(플레이어 20칸 안 따라오기, 96칸 밖이면 다음 무대에서 다시 소환).
- 팬텀 훔치기 대상이 각 전투에 반드시 하나 이상 있게 (`lastSkill` 기록 확인).
- 자막·대사는 `assets/flightsuit/lang/ko_kr.json`·`en_us.json`에 `dbz.flightsuit.<인물>.<키>`로. 원작 대사를 그대로 베끼지 않고 뜻만 살려 짧게.

## 4. 묶음 D: 마을 (시간이 남을 때만)

- **서쪽 도시**: 캡슐 코퍼레이션(`DbzLandmarks`) 주변 반경 60칸에 둥근 돔 집 8채(흰 콘크리트 + 노란 띠), 도로(회색 콘크리트), 가로등, 가게 3채. `TownsfolkEntity`를 역할 `CITIZEN`으로 10명, 가게 거래는 `TownTrades`에 제니(새 화폐 아이템 `zeni`, 에메랄드 1 = 제니 5) 추가. 캐릭터 체형·스킨은 `tools/TownsfolkGen.java`에 드래곤볼 옷차림 2~3종.
- **나메크 마을**: `DbzSaga.namekVillage`를 흰 돔 집 10채 + 아지사 나무(참나무 원목 + 청록 잎 블록) + 나메크인 주민 6명(덴데 스킨 변형)으로 확장.

## 6. 이미 결정된 것 (다시 묻지 않음)

- 사용자 결정: 궁극기 키 `V`; 트랭크스 궁극기 = 초사이어인 토글, 에너지가 빠르게 닳음; 팬텀 훔친 기술 슬롯 하나·영구 보관; 저지먼트 드로우 그대로; 템페스트 = 하늘에서 쏟아지는 궁극기; 셀 흡수 장면은 17호·18호 둘; 기뉴 등은 사람보다 크게; 명장면 전부 컷신으로, 자유도 유지하며 흐름을 자세히; 전투 모션을 진짜처럼; 그 전투에서 팬텀이 기술을 훔칠 수 있어야 함.
- Claude 판단(확인 필요로 표시할 것): 묶음 순서 A→B→C→D와 D 후순위; 헐크버스터 네더라이트 레시피; 1장에서 손오공이 라데츠 사망 뒤 베지터전 중간까지 빠짐; 거대원숭이만 전용 모델이고 나머지는 스킨 + 공용 포즈; 모든 수치(FE·대기·피해·체격).
- 하지 않는 것: GeckoLib 도입, 행성 지형 개편, 1인칭 헐크버스터 팔 크기, 다른 슈트(Mark 1·2·4·50)의 궁극기, 나메크성 포룽가.
