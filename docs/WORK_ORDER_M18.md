- 로컬 세션: `./gradlew build`가 됨. 묶음마다 빌드해서 컴파일 오류를 없앤 뒤 다음 묶음. git은 `-c safe.directory=<repo>`.
- 커밋은 묶음마다 (사용자 테스트 전이라도 묶음 단위로 커밋해 두고, main 병합은 테스트 뒤).
- 코드 주석 영어, 문서·대사·툴팁 한국어 + 영어(en_us). 수치는 전부 `SuitTuning`/`PowerTuning`/`VillageTuning`.
- 기·에너지 그림은 파티클이 아니라 `fx/KiFx`. 새 아이템은 `tip.flightsuit.<id>` + 안내서.

## 1. 묶음 A: 슈트

### A-0. 공통

- **키 여섯 개를 모든 슈트에**: 우클릭(주무기) · `Z`(방어/이동) · `X` · `C` · `V`(궁극기) · `B`(보조). `B`는 팬텀 전용 "훔친 기술"에서 **슈트별 보조 기술 칸**으로 넓힘 (팬텀은 그대로 훔친 기술). HUD 줄에 여섯 개 상태 전부.
- **무기 아이템** (사용자: "우클릭 꾹 누르는 조작감이 별로"): 검을 쓰는 슈트는 **풀세트를 입으면 무기 아이템이 손(핫바)에 생김** (`suit/SuitWeaponItem`: 버릴 수 없음, 상자에 못 넣음, 흉갑을 벗으면 사라짐, 접속할 때 다시 맞춤). 좌클릭 = 베기 콤보(허공 좌클릭도 패킷으로), 우클릭 = 그 무기의 자세 기술. 트랭크스 Mark 5 검, 황혼의 용사 Mark 4 마스터 소드(왼손 하일리아 방패는 그림), 비숍 Mark 7 지팡이, 캐논 슈터 Mark 6 대포. 손이 비어 있어야 하던 기존 주무기 규칙은 **손이 무기인 슈트(Mark 0·1·2·44·팬텀)만** 유지.
- **나노텍 Mark 50 삭제**: `NANO_MK50`, `NanotechHandler`, 재질 `MARK_50`, 스킨·모델·번역·`tools/NanoSuitGen.java`. 타노스 승리 보상 → 흉갑 배터리 업그레이드 +1단계(이미 최대면 아크 원자로 4) + 아크 원자로 2.
- **팬텀 대결(C, 블랙잭)**: 이기면 **보스도 즉사** (`DUEL_BOSS_DAMAGE` 폐기). 드래곤볼 보스는 체력 이정표 컷신을 건너뛰고 쓰러지는 것으로 처리.
- **R 슈트 휠**: 카드가 7개 이상이면 격자 배치, 둘째 줄(출처·충전·내구)을 두 줄로 나누고 카드 폭에 맞춰 자름.

## 2. 묶음 B: 공장식 전력

- **케이블 블록** (`block/CableBlock`): 6px 관, 이웃 케이블·전력 블록과 이어짐. 케이블로 이어진 전력 블록은 거리와 상관없이 같은 망. 무선 반경 8은 그대로 (사용자 결정, 나중에 밸런스).
- **발전소** (`block/PowerPlantBlock`): 석탄을 넣는 큰 발전기 (출력 200 FE/틱, 석탄 1 = 16,000 FE, 슬롯 9). 굴뚝 연기.
- **기술자** (`ResidentJob.ENGINEER`, 스킨 `tools/ResidentSkinGen.java engineer`): 마을의 발전소·발전기에 회관 창고의 석탄을 날라 넣고, 발전소 옆에서 일함. 게시판 소식 "오늘 발전 N FE". 작업장 설계도 "발전소" 추가.
- 전력 수치 표시: 케이블·발전소 툴팁 + Shift.

## 3. 묶음 C: 살아 있는 마을 (성채·히어로 시티·서쪽 도시 공통, 내 마을은 일부)

1. **일과표**: 아침 일터 → 정오 식당/광장에서 먹기(앉기) → 저녁 광장·주막 → 밤 집에서 잠(침대에 눕기) → 비 오면 실내.
2. **건물마다 하는 행동**: 식당(요리사 뒤 카운터, 돈으로 요리 구매 - 성채 주막, 히어로 시티 다이너, 서쪽 도시 식당), 여관 주인(소문), 대장간 망치질, 시장 시간대 개장, 훈련장 병사 대련, 성문 경비 교대.
3. **보이는 물류**: 농부가 밀을 들고 창고로, 요리사가 창고에서 식당으로, 상인이 시장과 창고 사이를 오감 (손에 든 아이템).
4. **갈 이유**: 여관 소문(성채·히어로 시티·다음 습격·도둑), 성채 **일기토 도전**(장수에게 [도전] 버튼 → 훈련장 1:1, 이기면 오수전 + 신뢰), 게시판 부탁 회전.
5. **나를 알아보기**: 신뢰도별 인사말(가까이 가면 한 번), 습격을 막아 준 뒤의 대사.
6. **성장**: 신뢰도 단계마다 시장 노점·집 증설, 사람 증가 (성채 15 → 최대 24명, 히어로 시티 21 → 30명).
7. **성채 찾기**: 성채 망루에 봉화(연기 기둥, 300칸 밖에서 보임), 히어로 시티는 본부 신호기 빛. **바닐라 마을**: 지도 제작자가 성채·히어로 시티 지도를 팖, 마을에 처음 가면 주민의 소문 한 줄.
8. **호버카**: 레시피 삭제. 부르마 대화에 [호버카 캡슐 사기 · 500 제니] 버튼.
- 부하: 마을당 사람 15~30명, 멀면(48칸 밖) 길 찾기 대신 순간 배치, AI는 20틱마다.
