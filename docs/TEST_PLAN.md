# 인게임 테스트 순서 (M10 ~ M16)

이 환경에서는 Forge 메이븐이 막혀 있어서 **한 번도 빌드해 보지 못했습니다.** 그래서 컴파일 에러부터 나올 수 있습니다. 빌드 에러가 나면 그 메시지를 그대로 붙여 주세요.

빠르게 확인하려면 크리에이티브 + 치트를 켠 새 월드를 쓰세요. 아래 명령어는 모두 `/flightsuit ...`(치트 필요) 또는 채팅 버튼이 대신 실행하는 명령어입니다.

## 0. 빌드

1. `./gradlew build`가 통과하는지 확인합니다.
2. `./gradlew runClient`로 월드에 들어가 크리에이티브 탭에 새 아이템이 보이는지 확인합니다.
   - 블록: 보안 센서, 발사대
   - 아이템: 배트맨 표식, 배트랭, 갈고리 총, 연막탄, 스카우터, 선두콩, 드래곤 레이더, 인피니티 건틀렛, 스톤 6개
   - 캡슐: 나노텍 Mark 50

## 1. 마을 준비 (M9 그대로)

1. 회관을 놓고 `/flightsuit village wanderer`로 주민을 몇 명 부릅니다.
2. 경비병 1명과 병사 2명을 둡니다.

## 2. M10 삼국지 습격 · M11 가족 · M12 성채

- **습격**: 마을 안에서 `/flightsuit raid start shu`
  - 웨이브 3번과 장수가 나오는지, 항복 버튼이 뜨는지 확인합니다.
  - [등용하기] / [돌려보내기]가 동작하는지 확인합니다.
- **가족**:
  - `/flightsuit village birth`로 아이가 태어나는지 확인합니다.
  - 아이를 클릭하면 주민 화면에 부모 이름이 나오는지 확인합니다.
  - `/flightsuit village grow`로 아이가 어른이 되는지 확인합니다.
- **성채**:
  - `/flightsuit fort tp wei`로 이동하면 성채가 지어지는지 확인합니다. 지도자는 왕좌에 있어야 합니다.
  - `/village list`
  - `/flightsuit fort trust wei 80` 다음 `/flightsuit fort request wei defend`로 방어 의뢰를 확인합니다.

## 3. M13 히어로 시티

1. `/flightsuit hero tp`로 이동해 도시가 지어지는지 확인합니다. 히어로 7명과 요원이 있어야 합니다.
2. 캡틴을 우클릭해 대사와 관계가 나오는지 확인합니다.
3. `/flightsuit hero trust 80`으로 관계를 올린 뒤 아이언맨을 우클릭합니다.
   - 수리, 업그레이드(다이아 4개), 아크 원자로, 선물 버튼을 확인합니다.
   - 캡틴 대화에 [타임 스톤] 버튼이 나오는지 확인합니다.
4. `/flightsuit hero request defend`로 악당 3웨이브가 오는지 확인합니다.
   - 20일째 이후라면 치타우리도 섞여 나와야 합니다.

## 4. M14 배트맨 일당

1. 상자 몇 개에 다이아·철을 넣습니다.
2. 마을 안에서 `/flightsuit thief now`를 입력합니다. 밤으로 바뀌고 도둑이 들어옵니다.
   - 상자 뚜껑이 혼자 열리는지 확인합니다.
   - 털린 상자에 배트맨 표식이 남는지 확인합니다.
   - 경비병이 발견하면 경보가 울리는지 확인합니다.
   - 배트맨이 EMP(스테이션 창고 잠금 풀림)를 쓰는지 확인합니다.
3. `/flightsuit thief spawn robin`으로 한 명만 불러 잡아 봅니다. 연막탄 3개를 떨어뜨려야 합니다.
4. 보안 센서를 전력망에 연결하면 빨간 렌즈가 켜지는지, 도둑이 근처에 오면 레드스톤 신호를 내는지 확인합니다.
5. 침대에서 바로 자면 아침 게시판에 결과가 나오는지 확인합니다.

## 5. M15 우주선과 드래곤볼 지구

1. 발사대를 하늘이 보이는 곳에 놓고 배터리·발전기로 충전합니다. 크리에이티브라면 발전기와 배터리를 여러 개 두세요.
2. 발사대를 우클릭하고 [드래곤볼 지구로 발사]를 누릅니다.
   - 우주선이 이륙하는지 확인합니다.
   - 별이 흐르는 화면이 나오는지 확인합니다.
   - 행성 하늘에서 내려와 착륙하고, 착륙 뒤 움직일 수 있는지 확인합니다.
3. `/planet`으로 목표를 봅니다. 그 다음 순서대로 진행합니다.
   1. 캡슐 코퍼레이션의 부르마: 선두콩과 레이더를 받습니다.
   2. 거북하우스의 손오공
   3. 크레이터의 라데츠: 손오공이 함께 싸우고, 스카우터를 받습니다.
   4. 다음 날 같은 크레이터: 재배맨 → 내파 → 베지터
4. **드래곤볼**:
   - 레이더를 들고 공을 찾아갑니다.
   - 빨리 보려면 `/flightsuit dragonballs give`로 7개를 받은 뒤 하나를 우클릭합니다.
   - 신룡이 나오는지, 소원 버튼이 동작하는지 확인합니다.
5. **차원을 넘는 원격 조종**:
   - 착륙한 우주선을 우클릭하고 [원격 접속]을 누릅니다. 집의 메인 스테이션 슈트로 들어가야 합니다.
   - 접속을 끝내면 행성의 몸으로 돌아오고, 슈트는 스테이션에 다시 들어가야 합니다.
6. 우주선을 우클릭하고 [귀환]을 누르면 발사대로 돌아오는지 확인합니다.

## 6. M16 타노스 사가

1. 발사대에서 [타이탄으로 발사]를 누릅니다.
   - 황혼 하늘인지 확인합니다.
   - `/planet`으로 경기장 방향을 확인합니다.
   - 블랙 오더를 쓰러뜨리면 스톤을 받는지 확인합니다.
2. 보르미르 첨탑을 사다리로 올라가 레드 스컬과 대화합니다. 경험치 30레벨을 내면 소울 스톤을 받습니다.
3. **최종전**:
   - 빨리 보려면 `/flightsuit thanos stones`(스톤 6개)로 스톤을 받은 뒤 마을에서 `/flightsuit thanos now`를 입력합니다.
     - 스톤을 다 가지면 타노스는 스톤 없이 옵니다.
     - 스톤을 빼고 해 보면 그가 스톤 기술을 씁니다.
   - 웨이브를 확인합니다: 치타우리 → 블랙 오더 → 타노스.
   - 히어로 시티 관계가 80이면 히어로 4명이 지원 오는지 확인합니다.
   - 이기면 나노텍 Mark 50 캡슐을 받는지 확인합니다.
     - 입으면 내구도가 저절로 차야 합니다.
4. **인피니티 건틀렛**:
   - 스톤 6개를 끼우고 우클릭하면 스냅이 일어납니다.
   - 타노스 군단이 재가 되는지, 내 체력이 반 칸이 되는지 확인합니다.
5. **패배**:
   - 10분 동안 타노스를 내버려 두면 주민 절반이 사라지는지 확인합니다.
   - 3일 뒤(`/time add 72000`) 마을에 가면 사라진 주민이 돌아오는지 확인합니다.

## 알려 주시면 좋은 것

- 빌드·실행 에러 메시지 전체
- 안 되는 기능, 너무 쉽거나 어려운 수치
- 의도와 다르게 느껴지는 부분. 기획서에 "Claude 판단"으로 표시된 곳이 특히 확인이 필요합니다.
