# 남은 인게임 확인 (2026-10-11, M18 묶음 A: 슈트 라인업)

M1~M17과 그 피드백은 통과했습니다. 아래는 M18 묶음 A의 확인 목록입니다. 말하지 않은 항목은 통과로 봅니다.

## 공통

- [ ] HUD 아랫줄이 두 줄: `[X] … · [C] … [V] …` 와 `[B] …` (버프가 켜지면 `◆초`, 헐크버스터 장갑 모드면 빨간 표시). 글자가 겹치지 않는가
- [ ] `R` 슈트 휠: 슈트가 7개 이상일 때 격자로 배치되고 카드 글자가 넘치지 않는가 (6개 이하는 원형)
- [ ] 무기 슈트(Mark 4·5·6·7) 흉갑을 입으면 핫바에 무기가 생기고, `Q`로 버리면 도로 들어오고, 상자에 넣고 흉갑을 벗은 뒤 꺼내면 사라지고, 흉갑을 벗으면 바로 사라지는가. 무기로 블록을 캐지 못하는가
- [ ] 동료 슈트(Mark 4·5·6·7)가 무기를 들고 싸우는가 (Mark 5는 싸울 때만)
- [ ] 안내서 19~22쪽, Shift 툴팁(슈트·무기·호버카 캡슐), JEI 정보

## 스크랩 Mark 0 (철·구리)

- [ ] 레시피: 파츠 4종(철·구리, 흉갑은 화로), 캡슐(철·구리·유리). 네더 없이
- [ ] 석탄·목탄·석탄 블록을 들고 우클릭 → "보일러에 석탄을 넣었습니다 (n / 8000 FE)", 가득 차면 "보일러가 가득". 스테이션 충전도 되는가
- [ ] 풀세트 비행이 느리고(55%) 날 때 등에서 연기. 빈손 우클릭 리펄서(약함)
- [ ] `X` 화염 방사(앞 원뿔 1.2초, 불), `C` 로켓 점프(착지 충격·블록 파티클), `V` 과부하(붉은 오라 8초, 빨라지고 세짐, 끝나면 소리), `B` 조명탄(하늘로 올라가 빨간 빛, 60초 밝음, 주변 몬스터 발광)

## 라이언 Mark 1 / 춘식이 Mark 2

- [ ] Mark 1 `V` 전방위 리펄서: 24칸 안 적들에게 좌우 손 번갈아 블래스트 → 마지막 미사일 전탄. `B` 이디스 스캔: 몬스터 발광 + 광석이 벽 너머로 색깔 빛으로 보임(10초)
- [ ] Mark 2 `X` 광선 드릴: 앞 6칸 3×3 굴착, 드롭이 가방으로, 광선 그림. `V` 투시 모드 15초(광석 색: 다이아 하늘, 금 노랑, 철 황갈, 구리 주황, 레드스톤 빨강, 청금석 파랑, 에메랄드 초록, 석탄 회색). `B` 발광 구슬: 보는 벽 앞에 60초 빛 (캐면 꺼짐)

## 팬텀 Mark 3

- [ ] `C` 카드 대결에서 이기면 보스(라데츠·베지터 등, 체력 100 이상)도 즉사하는가. 드래곤볼 장면이 다음으로 넘어가는가

## 황혼의 용사 Mark 4 (검 아이템)

- [ ] 검 들고 좌클릭 베기(누르고 있으면 연속), 체력 가득이면 검기. 우클릭 유지 = 방패 들기(앞의 근접·화살을 막고 천천히 걸음, 패링 모션)
- [ ] `V` 트라이포스의 힘(금빛, 10초 동안 체력과 상관없이 검기·대회전), `B` 질풍 부메랑(초록 원반이 16칸 나갔다 돌아오며 적을 멈춤)

## 트랭크스 Mark 5 (검 아이템)

- [ ] 검 들고 좌클릭 3단 베기(가로·세로·찌르기, 모션 세 가지). 우클릭 유지 = 손에 기가 모이고 0.8초 뒤 소리 → 떼면 큰 베기 + 검기 원반이 날아감
- [ ] 베는 순간 앞에서 오는 화살·기탄이 베이는가. `B` 기탄 연사 5발. `V` 초사이어인 그대로

## 헐크버스터 Mark 44

- [ ] `Z` 길게 장갑 모드(못 움직임, 피해 70% 감소, 연기), 떼면 충격파. `V` 잭해머(조준한 적을 앞에 붙잡고 10연타, 마지막에 날림), `B` 블록 던지기(조준한 땅 2×2×2가 뜯겨 날아가 조준 지점에 떨어짐)

## 캐논 슈터 Mark 6 (대포 아이템, 원숭이)

- [ ] 레시피(Mark 1 파츠 + 구리 블록 + TNT + 금 / 캡슐 + 구리 블록). 풀세트를 입으면 원숭이가 옆에 나타나 따라오는가 (걸으면 뛰어오고, 날면 어깨 옆에 뜨고, 24칸 멀어지면 옆에 다시 나타남). 흉갑을 벗으면 사라지는가
- [ ] 대포 들고 우클릭 유지: 포물선 포탄(검은 공, 연기), 반경 3칸 폭발·넉백, 반동. 조준점 근처에 떨어지는가. 대포를 든 모습(어깨 각도)이 어색하지 않은가
- [ ] `Z` 반동 점프, `X` 몽키 밀리샤(원숭이 셋이 10초 동안 불덩이), `C` 롤링 캐논(3발 부채꼴), `V` 빅 휴즈 자이언틱 캐논볼(큰 공이 느리게 날며 적을 밀어 넘기고 끝에서 큰 폭발), `B` 몽키 러시(원숭이 셋이 앞으로 돌진)
- [ ] 동료 Mark 6가 거리를 두고 포격하는가

## 비숍 Mark 7 (지팡이 아이템)

- [ ] 레시피(Mark 1 파츠 + 금 + 자수정 + 다이아 / 캡슐 + 자수정). 지팡이 들고 우클릭 유지: 아군(동료 슈트·주민·플레이어)을 보면 금빛 광선 + 회복(초록 파티클), 적을 보면 피해(언데드는 불)
- [ ] `Z` 홀리 매직 쉘: 켜면 오라, 2초 동안 스켈레톤 화살·블레이즈 화염구·드래곤볼 기탄이 막히고, 켠 직후 맞은 것은 되돌아가는가
- [ ] `X` 엔젤 레이(관통 빛, 적 피해·아군 회복), `C` 빛의 사슬(묶임, 보스는 짧게), `V` 제네시스(흰 섬광, 아군 완전 회복, 적에게 빛기둥), `B` 헤븐즈 도어(아군에게 고리, 15초 안에 치명타를 맞으면 토템 효과처럼 살아남고 3초 전 체력)
- [ ] 동료 Mark 7이 내가 다치면 회복 광선을 쏘는가
