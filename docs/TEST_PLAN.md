# 인게임 테스트 남은 것 (2026-10-10)

M10~M16과 1~4차 피드백 반영분은 사용자 테스트를 통과해서 목록에서 지웠습니다 (사용자: "말 안 한 것들은 다 테스트 통과"). 아래는 아직 확인하지 않은 것만 남깁니다. 빌드 에러가 나면 그 메시지를 그대로 붙여 주세요.

## 1. 4차 피드백 뒤에 바뀐 것

- **팬텀 순간이동 카드**: 팬텀 슈트로 Z 조준 → 클릭. 두 곳에서 **카드 그림 파티클**이 몸을 감싸며 돌다가, 0.5초 뒤 이동하면서 흩어지는지 확인합니다 (예전엔 연기만 보였음).
- **JEI·툴팁**: 인벤토리에서 우리 아이템(예: Mark 1 흉갑)에 마우스를 올리고 R → 조합법, U → 쓰임새, 정보 탭이 나오는지 봅니다. Shift를 누르면 툴팁에 사용법이 나오는지 확인합니다.
- **스토리 길안내**: 드래곤볼 지구에서 화면 위에 화살표·목표·거리가 나오는지, 돌아서면 화살표가 따라 도는지, 목표 위에 금빛 빛기둥이 보이는지 확인합니다. 40칸 안에 들어가면 표시가 사라집니다.

## 2. 드래곤볼 1장 끝 ~ 4장

`/planet`으로 다음 목표를 확인하며 진행합니다. "다음 날"은 해 뜰 때(게임 시간 0) 날짜가 바뀌는 기준입니다. 치트로 넘길 때는 `/time set`이 아니라 `/time add 24000`을 쓰세요 (`set`은 날짜를 되돌림).

- **1장 끝**: 라데츠 다음 날 크레이터 40칸 안 → 재배맨 → 내파 → 베지터(손오공 합류) → 1장 클리어.
- **2장 나메크성**: 부르마에게 말을 걸면 발사대 목록에 나메크성이 생기는지 봅니다. 나메크성에 가서 마을의 덴데와 이야기합니다.
  - 나메크 마을 방어(병사 → 도도리아 → 자봉), 기뉴 특전대, 프리저를 차례로 깹니다.
  - 자봉·프리저가 체력 절반에서 변신하는지, 프리저 때 손오공이 오는지 확인합니다.
- **3장**: 지구 캡슐 코퍼레이션의 트랭크스와 이야기 → 인조인간 → 다음 날 셀 게임 → 트랭크스 Mark 5 캡슐을 받는지 확인합니다.
- **4장**: 마인 부우 → 꼬마 부우에서 손오공의 원기옥이 터지는지, 채팅에 모인 기와 피해가 나오는지 확인합니다.
- 새 인물 17명의 스킨과 대사가 어색하지 않은지 봐 주세요.
