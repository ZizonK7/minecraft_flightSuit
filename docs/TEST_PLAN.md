# 남은 인게임 확인 (2026-10-10)

M1~M17과 M17 테스트 피드백(기 기술 그림, 컷신 카메라, 번역 누락)은 인게임 테스트를 통과했습니다. 지난 테스트 목록은 git 기록에 있습니다.

## 다음 작업

- [ ] **재배맨 모델** ("너무 못생겼어"): 새로 만든 뒤 여기에 확인할 것을 적습니다.

## 참고: 확인용 명령 (치트)

- `/flightsuit dbz fx <이펙트>`: 기 기술 그림 하나를 내 앞에 (피해 없음). `kamehameha, galick, special_beam, death_beam, candy, unibeam, charge, disc, ki, burning, fireball, blast, ring, spirit_bomb, pillar, aura, kaioken, flare`
- `/flightsuit dbz cutscene <id>`: 컷신을 내 앞에서 바로. `/flightsuit dbz stage <단계>`, `/flightsuit dbz stop`
- 날짜 넘기기는 `/time add 24000` (`/time set`은 날짜를 되돌림)
