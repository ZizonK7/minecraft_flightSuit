# M17 인게임 테스트 (2026-10-10)

M17(슈트 3벌 기술, 컷신 엔진, 드래곤볼 1~4장 재구성, 서쪽 도시·나메크 마을)은 클라우드 세션에서 만들었고 **컴파일도 인게임 확인도 못 했습니다**. 그래서 순서는:

1. `./gradlew build` → 에러가 나면 **메시지 전체를 그대로** 붙여 주세요. 그것부터 고칩니다.
2. `./gradlew runClient`로 아래를 차례로. 안 되는 것, 어색한 것, 너무 쉽거나 어려운 수치를 알려 주세요. DESIGN.md 5장 "M17"의 **Claude 판단** 목록이 특히 확인이 필요합니다.

치트가 필요한 명령은 크리에이티브 + `/gamemode creative` 기준입니다. 슈트는 크리에이티브 탭 "플라이트 슈트"의 **슈트가 든 캡슐**로 바로 입을 수 있습니다.

## 1. 공통: 새 키

- [ ] 조작 설정에 `V` (궁극기), `B` (훔친 기술 쓰기)가 있고, 안내서 18쪽·Shift 툴팁의 키 이름이 바꾼 키를 따라가는지.
- [ ] Mark 1·2·4·50에서 `V`·`B`를 눌러도 아무 일 없이 조용한지 (에러·이상한 메시지 없음).

## 2. 헐크버스터 Mark 44

- [ ] **입기**: 캡슐이나 스테이션으로 입을 때 하늘에서 **베로니카 포드**가 떨어져 열리고 장갑이 붙는지. 풀세트에서 몸이 1.5배.
- [ ] **주먹 연타**: 빈손 우클릭 유지 → 좌우 번갈아 주먹 (리펄서가 안 나감). 좀비 무리에 앞쪽 부채꼴로 맞고 밀려나는지.
- [ ] **벽 충돌**: 몹을 벽 쪽으로 때려 날리면 0.5초 안에 부딪힐 때 추가 피해(파편 입자).
- [ ] `X` **피스톤 펀치**: 8칸 안의 적에게 돌진해 5연타, 마지막 한 방에 기절(2초). 그동안 내가 받는 피해가 줄어드는지. 1,500 FE, 10초 대기 (HUD 아랫줄).
- [ ] `C` **지면 강타**: 땅에서 = 반경 6칸 충격파로 띄움. 날다가 = 수직으로 내리꽂고 충격파. 2,000 FE, 8초.
- [ ] 스켈레톤 화살 피해가 절반인지, 걸어가며 닭·고양이 같은 작은 몹을 밀어내는지, 비행이 Mark 1보다 조금 느린지.
- [ ] **동료**로 내보내면 적 앞에서 땅에 내려와 주먹·피스톤·강타를 쓰는지.
- [ ] 레시피: 파츠 = Mark 1 파츠 + 철 블록 + 금 블록 + 네더라이트 주괴, 캡슐 = Mark 1 캡슐 + 네더라이트 주괴 (JEI `R`).

## 3. 트랭크스 Mark 5

- [ ] **3단 베기**: 빈손 우클릭 유지 → 가로 → 세로 → 찌르기 (등의 검이 손에 나타나고, 멈추면 1초 뒤 다시 등에). 세 번 다 같은 적에 맞으면 기절. **날면서도** 되는지.
- [ ] **투사체 베기**: 베는 동안 스켈레톤 화살, 드래곤볼 보스 기탄이 앞에서 오면 베어지는지.
- [ ] `X` **버닝 어택**: 1초 손을 모았다가 불꽃 기탄이 날아가 터짐 (반경 3칸). 1,800 FE, 8초.
- [ ] `C` **섬광 베기**: 12칸 앞으로 순식간에 이동하며 길 위의 적을 모두 벰, 그동안 무적. 벽 앞에서는 벽에서 멈추는지.
- [ ] `Z` **검 패링**: 맞기 직전 짧게 → 막고, 다음 베기가 2배.
- [ ] `V` **초사이어인**: 금빛 머리(금발 텍스처)·금빛 오라·빨라짐, 피해 1.5배. 켜면 2,000 FE, 켜 있는 동안 초당 400 FE. 다시 `V` = 끔. 배터리 10% 아래면 저절로 풀리고 5초 못 켬. 죽거나 나가면 풀리는지.
- [ ] 동료로 내보내면 검으로 싸우는지 (3단 베기·버닝 어택·섬광 베기).

## 4. 팬텀 Mark 3

### 4-1. 순간이동 (`Z` 짧게 → 떼면 조준, 클릭 = 이동, 다시 `Z` = 취소)

- [ ] **마우스 휠**로 거리(4~40칸)가 바뀌고 원이 따라 움직이는지. HUD/원 색: 보라 = 가능, 빨강 = 불가.
- [ ] 상황 6가지 (모두 원이 보여 준 곳에 실제로 도착해야 함):
  1. [ ] **몬스터를 조준** → 그 등 뒤.
  2. [ ] **평지 바닥**을 조준 → 그 자리.
  3. [ ] **턱·난간·지붕 위**(2칸 공간이 있는 블록 윗면)를 조준 → 그 위로 올라감.
  4. [ ] **벽 옆면**(위에 공간 없음) → 벽 바로 앞.
  5. [ ] **하늘**(아무것도 안 맞음) → 시선 끝에서 8칸 아래까지 땅이 있으면 그 위, 없으면 공중: **카드 한 장을 밟고 1초** 섰다가 천천히 내려옴 (낙하 피해 없음).
  6. [ ] **아래 구멍**(절벽·동굴 입구)을 내려다보고 → 바닥까지.
- [ ] 비용이 거리에 따라 다른지 (100 + 칸당 7.5 FE, 40칸 = 400 FE), 출발·도착 카드 소용돌이.

### 4-2. 기술 훔치기 (`Z` 길게 0.5초) / 쓰기 (`B`)

- [ ] 바닐라 몹: 크리퍼 → 크리퍼 폭발, 블레이즈·가스트 → 화염구, 엔더맨 → 순간이동, 이보커 → 송곳니, 위더 스켈레톤 → 시듦 베기. 카드 3장이 날아가 감싸고 돌아오며 HUD 아랫줄에 기술 이름.
- [ ] 드래곤볼 인물: 보스가 **최근 8초 안에 쓴 기술**만 훔쳐짐 (아직 아무것도 안 썼으면 "아직 본 게 없다"). 같은 인물에게서 같은 기술은 한 번만.
- [ ] 15종을 `B`로 써 보기 (치트로 구하기 어렵다면 각 장의 보스에게서): 에네르기파, 갤릭포, 데스 빔, 마관광살포(나선 빔), 태양권(주변 실명), 기원참(원반), 계왕권(8초 강화 뒤 체력 소모), 순간이동(조준한 적 옆), 자폭, 캔디 빔(맞은 적이 작아짐: 공격 못 하고 피해 2배), 크리퍼 폭발, 화염구, 엔더맨 순간이동, 송곳니, 시듦 베기.
- [ ] 새로 훔치면 덮어쓰고 채팅에 "A → B". **재접속·죽은 뒤에도** 훔친 기술이 남는지.
- [ ] `V` **템페스트**: 카드를 하늘로 던지는 동작 → 조준 지점 반경 10칸에 4초 카드 폭우 (적이 느려지고, 나는 적은 아래로 눌림). 6,000 FE, 60초.
- [ ] 동료 팬텀이 적 5마리 이상이면 템페스트를 쓰는지.

## 6. 드래곤볼 이야기 (장별 흐름)

이미 진행한 월드는 단계가 이름으로 옮겨집니다 (예전 저장 → 그대로 이어짐). 처음부터 보려면 `/flightsuit dbz stage arrived`. 단계를 건너뛸 때: `/flightsuit dbz stage <단계>` (단계 이름은 탭 자동완성, "다음 날" 기다림도 풀림), 전투를 끝내려면 `/flightsuit dbz stop`. 날짜를 넘길 때는 `/time add 24000` (`/time set`은 날짜를 되돌림). `/planet`으로 다음 목표.

- [ ] **1장 라데츠** (`met_goku`): 크레이터 40칸 안 → 포드 추락 컷신, 손오공·피콜로와 싸움 → 50% 오반 박치기 → 10% 마관광살포 → 스카우터. 그 뒤 거북하우스에 손오공이 없는지.
- [ ] **1장 사이어인** (`raditz_beaten`, 다음 날): 착륙 컷신 → 재배맨 6 (아군 다섯) → 마지막 하나에서 야무치 컷신 → 내파 → 30% 피콜로의 희생 → 오반 흰 오라 10초 → 끝나면 바로 **베지터** (`nappa_beaten`) → 70% 계왕권(손오공 등장, 붉은 오라) → 40% 거대원숭이 (4배 크기 모델이 보이는지, 꼬리가 흔들리는지) → 30% 야지로베 → 다시 베지터 → 쓰러지면 보내 주는 컷신 → 1장 클리어.
- [ ] 장면이 끝난 뒤 아군이 나를 따라오는지 (멀면 날아옴, 96칸 넘게 멀어지면 사라짐). 다음 장면이 시작되면 그 장면의 아군으로 바뀌는지.
- [ ] **2장** (`saiyans_beaten` → 부르마): 부르마 대화 3줄 → 나메크성 → 덴데 대화 3줄 → 마을 방어 (나메크인 6명은 싸움 동안 집으로) → 기뉴 특전대 포즈 컷신(+ 손오공 착륙) → 굴도 → 리쿰 → 버터·지스 → 기뉴 → 프리저: 50% 최종 형태 + **크리링·초사이어인 컷신** (손오공이 금발 스킨으로 바뀌는지) → 15% 행성 핵: **3분 보스 바**, 번개, 10초마다 용암 구덩이 → 시간 안에 쓰러뜨리면 탈출 컷신, 못 하면 실패 메시지 후 처음부터 (용암 구덩이는 원래대로 돌아오는지).
- [ ] **3장** (`frieza_beaten`): 지구 캡슐 코퍼레이션 앞 24칸 안 → 타임머신 컷신 → 트랭크스와 대화 3줄 → 무너진 길: 17호·18호 (아군 트랭크스·16호·크리링) → 둘 다 무릎 꿇으면 셀 흡수 컷신 둘 → 다음 날 셀 게임 링: 관중석·관중·미스터 사탄·아나운서 → 셀 주니어 6 → 오반 각성 컷신 (청년 오반 → 초사이어인 2 스킨) → 셀 20% 자폭·순간이동 → 10초 뒤 셀 재등장 → 부자 에네르기파 → 트랭크스 Mark 5 캡슐 + 검.
- [ ] **4장** (`cell_beaten`): 바비디 우주선: 마인 부우 30% → 미스터 사탄 컷신 → 악의 부우 컷신 (아군에 청년 오반·피콜로·트랭크스 추가) → 50% 흡수 컷신 (스킨 바뀜, 더 단단해짐) → 쓰러지면 꼬마 부우 컷신 → 황무지: 꼬마 부우 + 원기옥 (채팅에 모인 기와 피해) → 쓰러지면 원기옥 엔딩 컷신 → 보상.
- [ ] 각 장면에 팬텀이 훔칠 기술을 쓰는 적이 있는지.
- [ ] 새 인물 17명 스킨 (미리보기 `docs/reference/dbz_preview.png`): 초사이어인 손오공, 소년·청년·초사이어인 2 오반, 피콜로, 크리링, 야무치, 천진반, 야지로베, 미스터 사탄, 1형태·최종 형태 프리저, 16호, 불완전체·반완전체 셀, 악의 부우, 흡수 부우. 체격(기뉴 특전대·내파·부우 등은 사람보다 큼).
- [ ] 싸움 모션: 3단 콤보와 타격 멈춤, 보스 가드(불꽃)·잔상 회피, 공중 격돌, 기탄이 날아가는 모습, 변신 빛기둥·땅 균열·화면 흔들림.
